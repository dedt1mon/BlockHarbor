# BlockHarbor 1.10

Лаунчер Minecraft Java Edition для Windows 11 x64 с установщиком и собственной иконкой зелёного куба. В одном окне можно выбрать сборку, настроить персонажа и запустить Minecraft для игры с друзьями через Steam. Исходный код входит в комплект. В BlockHarbor нет рекламных блоков, аналитических SDK и платных функций.

**[Скачать установщик](https://github.com/dedt1mon/BlockHarbor/releases/latest)** · [Изменения версий](CHANGELOG.md) · [Сообщить об ошибке](https://github.com/dedt1mon/BlockHarbor/issues)

## Установка и первый запуск

1. Скачай **BlockHarbor-Setup-1.10.0.exe** и открой двойным щелчком. Мастер установки работает на русском языке.
2. Выбери папку приложения. По умолчанию используется `%LOCALAPPDATA%\Programs\BlockHarbor` для текущего пользователя Windows.
3. Отметь **Создать ярлык на рабочем столе**, если он нужен. Установщик также добавит BlockHarbor в список приложений меню **Пуск**. Можно отдельно выбрать помощь с закреплением на панели задач и на начальном экране. После установки мастер покажет инструкции и предложит открыть установленный ярлык в Проводнике; само закрепление подтверждается через меню Windows.
4. Заверши установку и открой BlockHarbor через ярлык. Встроенный пакет включает Python, библиотеки и интерфейс. При первой подготовке откроется консоль с прогрессом проверки и распаковки.
5. На чистой установке список сборок пуст. Нажми **Новая сборка**, выбери Minecraft и загрузчик или нажми **Загрузить сборку**, чтобы импортировать ZIP друга.
6. Укажи **Ник в игре** и нажми **Играть**. Для выбранной версии лаунчер автоматически подготовит Java, файлы Minecraft, загрузчик и поддерживаемые сетевые компоненты. Первой загрузке нужен интернет. Во время подготовки виден текущий этап.

Когда подготовка закончится, откроется Minecraft. Последующие запуски используют установленные компоненты. Иконка зелёного куба встроена в EXE, установщик и программу удаления. Ярлыки Windows используют эту иконку.

### Обновление и удаление

Для обновления закрой Minecraft и прежний BlockHarbor, затем запусти новый установщик. Он использует зарегистрированную папку приложения. При переходе с переносимой версии игровые данные находятся в том же профиле `%LOCALAPPDATA%\BlockHarbor`. Удаление прежних примеров выполняется через **Сборки → Удалить**.

Для удаления приложения открой **Параметры Windows → Приложения → Установленные приложения → BlockHarbor → Удалить** или **Пуск → BlockHarbor → Удалить BlockHarbor**. Удаляются программа, её ярлыки и запись в списке приложений. Игровой профиль в `%LOCALAPPDATA%\BlockHarbor` доступен после повторной установки.

Программа распаковывает свои рабочие файлы в отдельный каталог внутри `%LOCALAPPDATA%\BlockHarbor\app`. При потере или изменении установленных компонентов следующий запуск EXE восстанавливает их из встроенного пакета. Новая версия программы получает отдельный каталог. Миры находятся в каталогах сборок.

Окно рассчитано примерно на 1360×840 при масштабе 100 %. На небольшом дисплее лаунчер подстраивается под доступную область экрана. Страницы с длинным содержимым можно прокручивать. В Windows лаунчер открывает отдельное окно через Edge, Chrome, Brave или Firefox. Если используется вкладка браузера по умолчанию, ограничение размера действует внутри этой вкладки.

Сборки Fabric и Forge 1.20.1 поддерживают игру через Steam и автоматический обмен скинами в общем мире. Создай такую сборку самостоятельно или импортируй ZIP, который выгрузил друг. Карту и сид выбирай в игре. BlockHarbor предназначен для владельцев Minecraft Java Edition. Файлы игры загружаются при первой установке.

После подготовки файлов и запуска Minecraft окно BlockHarbor автоматически скрывается. Когда игра закрывается, лаунчер возвращается на прежний экран. При ошибке запуска или аварийном выходе сообщение можно прочитать в лаунчере. Если нужно открыть его во время игры, дважды нажми `BlockHarbor.exe`. В режиме Microsoft через Prism настройка аккаунта проходит с открытым окном BlockHarbor. Автоматическое скрытие в Windows работает в отдельном окне Edge, Chrome, Brave или Firefox.

## Профиль игрока

По умолчанию BlockHarbor напрямую запускает Minecraft с локальным ником. Такой профиль подходит для одиночной игры и сервера, принимающего локальные профили. В одиночном мире смена локального ника меняет UUID персонажа, и игра может открыть отдельный инвентарь.

Для сервера с проверкой Microsoft выбери **Настройки → Профиль запуска → Microsoft через Prism**, нажми **Сохранить настройки** и вернись к кнопке **Играть**. При первом использовании следуй подсказкам для входа в Microsoft-аккаунт с Java Edition. После настройки сборка запускается из BlockHarbor той же кнопкой.

## Ник и скин

1. На главной выбери сборку для игры. Если Minecraft уже запущен, закрой его перед сменой скина в этой сборке.
2. Открой **Профиль**, укажи **Ник в игре**, нажми **Выбрать скин игрока** и открой свой PNG. Для скина 64×64 выбери модель **Classic** или **Slim**. Для 64×32 подходит **Classic**.
3. Нажми **Сохранить все параметры** и дождись сообщения **Успешно сохранено**. Если для выбранной Vanilla-сборки доступен Fabric, лаунчер предложит **Установить и сохранить**. Переход сохранит версию Minecraft и миры.
4. На главной нажми **Играть**. В игре нажми F5 или открой инвентарь, чтобы увидеть своего персонажа.

**Чтобы друзья увидели локальный скин в вашем мире**, хозяин и гости запускают поддерживаемую сборку с одной версией Minecraft и одним загрузчиком. Например, хозяин создаёт сборку Fabric 1.20.1, выгружает её ZIP и отправляет друзьям для импорта. Хозяин открывает мир для сети. Когда друзья входят, Skinss+ передаёт участникам выбранные скины. BlockHarbor устанавливает компонент автоматически, в том числе игрокам, которые оставили стандартный скин. Пересылать PNG или карточки друг другу для этого не требуется.

В BlockHarbor 1.10 сетевой обмен доступен на Fabric и Forge для **1.18.2, 1.19.2, 1.19.4, 1.20.1, 1.20.2 и 1.21.8**. На выделенном сервере администратору также нужно установить Skinss+ для его версии игры и загрузчика. На других совместимых с CustomSkinLoader сборках сохранённый PNG доступен на твоём компьютере. В **Профиль → Карточки друзей** остался ручной обмен скином и псевдонимом для Fabric 1.20.1.

**Для Vanilla и серверов с официальными скинами** выбери PNG и модель в разделе **Профиль**. Нажми **Сохранить только для Java-профиля**. В Vanilla и других сборках без поддержки локальных скинов этот вариант появляется после нажатия **Сохранить все параметры**. Лаунчер сохранит PNG и модель на компьютере. Затем открой **Установить скин в Java-профиле → Скачать мой PNG**. Нажми **Открыть Minecraft.net**, войди в свой аккаунт с Java Edition, выбери модель и загрузи PNG. Если ты уже вошёл через **Свой Microsoft Client ID**, в лаунчере доступна кнопка **Применить к аккаунту**. Затем войди в Minecraft под этим Java-профилем. На сторонних серверах с собственной системой скинов отображение определяет сервер. [Профиль Minecraft](https://www.minecraft.net/msaprofile/mygames)

## Передать сборку другу

Открой **Сборки**, нажми **Выгрузить** в строке нужной сборки и выбери **Скачать ZIP**. В архив входят версия игры и загрузчик, установленные моды, шейдеры, ресурс-паки и совместимые файлы настроек. Если хочешь передать и свои миры, закрой Minecraft и отметь **Включить сохранённые миры**.

На другом компьютере открой **Сборки → Загрузить сборку** и выбери этот ZIP. Лаунчер создаст и выберет новую сборку. Если такое название уже есть, к новой копии добавится номер. Скины персонажа, данные входа в лаунчер и журналы хранятся отдельно от архива.

## Создание сборок и дополнения

Открой **Сборки → Новая сборка**, дай ей название и выбери версию Minecraft и загрузчик. Список содержит все стабильные релизы Java Edition из каталога Mojang. Комплектный список доступен сразу. При открытии формы лаунчер проверяет обновления каталога с учётом локального кэша. Кнопка **Обновить список релизов** запрашивает свежие данные вручную.

В совместимой сборке BlockHarbor подготовит компоненты для игры через Steam во время создания. Существующая сборка получит их при следующем запуске. Для обычной игры без модов выбери **Vanilla**.

Открой **Сборки**. Нажатие на название выбирает сборку для игры. Чтобы изменить её содержимое, нажми кнопку **Настройки** с шестерёнкой в той же строке. В открывшейся сборке выбери **Моды**, **Шейдеры** или **Ресурс-паки**.

Рядом с установленными файлами отображаются их иконки. Лаунчер использует изображение из JAR/ZIP или сохранённую иконку проекта Modrinth, когда она доступна. Для дополнений без изображения показан значок соответствующей категории. Иконки сохраняются локально; повторное открытие списка не требует обращения к Modrinth.

- **Скачать с Modrinth** открывает каталог для этой категории и версии Minecraft. Для модов учитывается и загрузчик. В результатах рядом с названием показана иконка проекта. При перелистывании текущий список остаётся видимым, пока загружается следующая страница. Введи название дополнения, открой проект в результатах, выбери **Совместимая версия** и нажми **Установить в сборку**. Лаунчер скачает выбранный файл и обязательные зависимости, которые автор указал в каталоге Modrinth, и проверит их контрольные суммы. Уже установленный выпуск помечен в списке. Если каталог сообщает о внешней зависимости, файлы проекта и такой зависимости можно добавить вручную.
- **Добавить файл** открывает выбор файла с компьютера. Для ручной установки подбери версии дополнения и его зависимостей под свою сборку.

**Фильтры каталога.** Открой **Фильтры** рядом с поиском. Можно включать и исключать категории, выбирать клиентскую или серверную сторону для модов, эффекты и нагрузку для шейдеров, особенности и разрешение для ресурс-паков. Также доступны открытая лицензия, поиск по зависимостям и дополнительные исключения. Нажми **Применить**. Сортировка рядом позволяет искать, например, самые скачиваемые или недавно обновлённые проекты. При смене страницы и возвращении из карточки твой выбор сохраняется.

**Совместимость.** В карточке выбери выпуск. Лаунчер покажет обязательные, необязательные и встроенные зависимости и сверит заявленные несовместимости с файлами сборки. Кнопка **Установить с зависимостями** скачает доступные обязательные файлы. Явное предупреждение автора можно подтвердить отдельно. Если после скачивания в JAR обнаружатся дополнительные условия, лаунчер покажет их перед добавлением файлов. При установленном дубликате или жёстком конфликте загрузчика выбери другой выпуск или убери конфликтующий файл. При ручном добавлении недостающие зависимости указаны для самостоятельной установки. Конфликты поведения, которых авторы не указали в метаданных, могут проявиться только в игре.

| Категория | Что добавить | Как включить в игре |
| --- | --- | --- |
| Моды | JAR для выбранного загрузчика и версии Minecraft | Запусти сборку с этим загрузчиком. Если Minecraft был открыт, перезапусти его. |
| Шейдеры | ZIP с папкой `shaders` | В сборке нужен совместимый мод для шейдеров, например Iris на Fabric. Выбери установленный шейдерпак в настройках графики Minecraft. |
| Ресурс-паки | ZIP с `pack.mcmeta` в корне | Открой **Настройки → Наборы ресурсов** в Minecraft и включи пакет. Ресурс-паки работают и на Vanilla. |

Корзина рядом с добавленным файлом удаляет его из выбранной сборки. Каждая сборка хранит собственные миры, моды, шейдеры, ресурс-паки и настройки. Для совместной игры сверьте версии игры, загрузчика и модов, которые требуются сервером и клиентами. Шейдеры и ресурс-паки могут различаться.

### Удаление и восстановление сборки

Открой **Сборки**, нажми **Удалить** в строке нужной сборки и проверь имя в окне подтверждения. Её миры, моды, шейдеры, ресурс-паки и настройки переместятся вместе в `%LOCALAPPDATA%\BlockHarbor\deleted-instances`. Удаление активной сборки переключит лаунчер на одну из оставшихся. Последнюю сборку тоже можно удалить.

Чтобы вернуть сборку, раскрой **Удалённые сборки** и нажми **Восстановить**. Эта возможность сохраняется после перезапуска. Для освобождения места в этом же списке выбери **Удалить с диска**. После отдельного подтверждения лаунчер сотрёт папку выбранной удалённой сборки вместе с мирами и дополнениями.

## Производительность

В **Настройки → Память Minecraft** пустое поле включает автоматический подбор памяти по объёму физической и доступной ОЗУ. Выбранный лимит находится между 1 и 6 ГиБ. Чтобы задать собственный лимит, введи количество МБ и сохрани настройки. После обновления ранее введённое число продолжает действовать. Для автоматического режима очисти поле и сохрани.

В **Сборки → Настройки → Дальность в игре** после первого запуска Minecraft 1.18 или новее можно уменьшить прорисовку до 8 чанков и симуляцию до 5 чанков. Перед применением показаны точные изменения. Меньшие установленные значения сохраняются. Кнопка возврата восстанавливает прежние значения. Во время игры редактирование недоступно.

Лаунчер получает состояние сборок без открытия SQLite для каждого JAR. Для скрытого окна интервал проверки задач увеличен до минуты. Возвращение окна после закрытия Minecraft отслеживает процесс игры.

## Как играть с друзьями через Steam

На обоих компьютерах должен быть запущен настольный Steam. Войдите каждый в свой аккаунт, добавьтесь в друзья и выберите в BlockHarbor одну и ту же версию Minecraft, загрузчика и игровых модов. Для Steam-соединения VPN, публичный IP и настройка портов не требуются. [Steam для Windows](https://store.steampowered.com/about/)

В **Друзья** есть кнопка **Открыть Steam**, сведения о совместимости выбранной сборки и инструкция для хозяина и гостя. После входа в Steam выберите одну и ту же сборку в BlockHarbor и нажмите **Играть** на главной. Поддерживаемую Vanilla-сборку можно перевести на Fabric кнопкой **Включить Steam в этой сборке**. Это сохраняет версию игры и каталог миров. Для первой подготовки сетевых компонентов требуется интернет.

В **Друзья → Проверить подключение** показаны установленные сетевые компоненты, версия загрузчика, код набора модов и сведения из последнего журнала Minecraft. Сравните код и версии с хозяином мира. При отключённом открытии мира или неверном Steam App ID доступно исправление настроек с резервной копией. Недостающие компоненты можно подготовить здесь же.

Кнопка **Открыть Steam** запускает установленный клиент. Если клиент отсутствует, открывается официальная страница установки. Каждый участник входит в собственный аккаунт Steam.

Загрузки компонентов учитывают доступный системный HTTP(S)-прокси и повторяют временные сетевые ошибки. VPN может продолжать работать во время игры, если пропускает игровой трафик Steam. При блокировке транспорта Steam или UDP нужно разрешить этот трафик в настройках VPN или воспользоваться его раздельным туннелированием. Сам лаунчер не может изменить ограничения VPN-сервера. Результат реального соединения виден в журнале сборки и проверке во вкладке **Друзья**.

### Закрытый мир для компании

1. Хозяин открывает одиночный мир и выбирает **Esc → Открыть для сети**. В настройках доступа выбирает **Для друзей Steam** или **Только по приглашению**, затем открывает мир.
2. В чате Minecraft появится кнопка **Пригласить друзей**. Хозяин нажимает её и отправляет приглашение другу через Steam.
3. Друг запускает совместимую сборку, принимает приглашение Steam и подтверждает вход в Minecraft. Хозяин остаётся в мире до конца игры. Оверлей Steam обычно открывается сочетанием **Shift + Tab**.
4. Если приглашение не появилось, проверьте режим доступа и онлайн-статус в Steam. Хозяин также может передать другу зелёный адрес вида `s-<id>-<код>.steam` из чата. Скопируй его целиком вместе с окончанием `.steam`. Его можно вставить в **Сетевая игра → Прямое подключение**. Адрес действует для текущего сеанса. [Инструкция e4steam](https://github.com/Kamilhik/e4steam/blob/v0.3.6/docs/GETTING_STARTED.md)

### Общий каталог миров

Чтобы опубликовать мир для других игроков, хозяин выбирает **Открыть для сети → Общий сервер**, подтверждает публикацию, указывает название и открывает мир. Гость открывает **Сетевая игра → Публичные серверы**, находит название и нажимает **Подключиться**. Для приватной игры используйте приглашение по инструкции выше. ## Данные и сборка из исходников

Данные сохраняются в `%LOCALAPPDATA%\BlockHarbor`. Кнопка **Папка сборки** открывает каталог конкретного экземпляра, включая `saves` с мирами. Если Minecraft завершится с ошибкой при прямом запуске, BlockHarbor покажет сообщение. Игровой журнал находится в `logs\latest.log` внутри папки сборки. Повторный запуск BlockHarbor открывает текущую сессию.

Режим **Свой Microsoft Client ID** нужен пользователям с собственным приложением, одобренным для Minecraft Services. Укажи Microsoft redirect URI `http://localhost:43821/callback`. Вход использует OAuth с PKCE. Обычный локальный запуск и Microsoft через Prism не требуют регистрации приложения.

Приложение слушает только случайный порт на `127.0.0.1`. Окну передаётся временный ключ сессии. Интернет используется при запросе каталога/файлов игры, установке выбранных компонентов, входе и сетевой игре. Добавляемые вручную моды выполняются внутри Minecraft. Лаунчер проверяет структуру импортируемого файла и соответствие категории.

В `tools/windows-lock.json` приведены поставщики, версии и контрольные суммы компонентов. Условия распространения включённых компонентов находятся в [THIRD_PARTY.md](THIRD_PARTY.md).

### Запуск исходников

Для исходного проекта нужен Python 3.11 или новее. Выполни команды в корне репозитория. После первого запуска готового EXE исходники также доступны внутри текущего каталога `files-…` в `%LOCALAPPDATA%\BlockHarbor\app`.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m unittest discover -s tests
.\.venv\Scripts\python main.py
```

### Сборка приложения и установщика

Для создания Windows x64 EXE нужны Python 3.10 или новее и Go. Для установщика дополнительно нужен NSIS 3.13 или новее. Команда сборки приложения получает закреплённый CPython и зависимости по HTTPS, сверяет SHA-256 и сохраняет архивы в кэш сборщика. Каталог назначения приложения должен быть новым или пустым.

```powershell
py -3.13 tools/build_windows.py --output ..\BlockHarbor-Windows-x64
py -3.13 tools/build_installer.py --launcher ..\BlockHarbor-Windows-x64\BlockHarbor.exe --output ..\BlockHarbor-Setup-1.10.0.exe --version 1.10.0 --project-url https://github.com/dedt1mon/BlockHarbor
```

Если NSIS отсутствует в `PATH`, укажи компилятор явно через `--makensis "C:\Program Files (x86)\NSIS\makensis.exe"`. Для переносимого компилятора можно передать каталог данных NSIS через `--nsisdir`. Самостоятельный `BlockHarbor.exe` также запускается двойным щелчком и содержит тот же пакет приложения.

Поведение ярлыков и сценарии ручной проверки установщика описаны в [инструкции для Windows](docs/windows-installer.md).

Иконка хранится в `ui/icon.ico`, её исходная геометрия находится в `ui/icon.svg`. После изменения SVG выполни `python tools/render_windows_icon.py` в окружении с Pillow и пересобери приложение. Генератор Windows-ресурсов помещает иконку и сведения о версии в EXE при обычной сборке.

Для проверки извлечённого пакета готовой сборки можно вызвать `.\runtime\python.exe -m unittest discover -s tests`. Проверка распаковщика выполняется командой `go test tools/bootstrap_payload.go tools/bootstrap_payload_test.go`. Лог запуска оболочки лежит в `%LOCALAPPDATA%\BlockHarbor\logs\startup.log`.
