# Скины игроков в BlockHarbor

Для общего скина оба игрока обновляют BlockHarbor и заново запускают Minecraft из лаунчера. Лаунчер подбирает проверенный выпуск CustomSkinLoader для версии игры и загрузчика, устанавливает его также игрокам без собственного PNG и добавляет источник общих скинов. Поддерживаются совместимые пары из `launcher/skin_releases.json`, включая NeoForge 1.21.1. Vanilla без загрузчика модов автоматически не преобразуется.

При локальном профиле перед запуском в сервис передаются только игровой ник, модель рук и нормализованный PNG 64×64. Другие клиенты получают PNG по этому нику через CustomSkinAPI. Отдельный мод на игровом сервере для этого способа не нужен; отображение происходит у клиентов с настроенным CustomSkinLoader. Скин из профиля лаунчера публикуется при следующем запуске игры. Для смены через игровое меню действуют условия ниже. Клиент другого лаунчера без этого источника не получит скин автоматически.

CustomSkinLoader сам по себе не пересылает локальный PNG друзьям. Прежний Skinss+ умеет сетевой обмен только на своём наборе Fabric/Forge и требует компонент на стороне игрового сервера; в частности, его нет для NeoForge 1.21.1. Для поддерживаемых старых пар он остаётся дополнительным способом обмена.

## Гардероб во время игры

Начиная с 2.6.15 BlockHarbor экспортирует сохранённые варианты гардероба
в каталог совместимого игрового селектора. Ник и UUID персонажа сохраняются.
Один раз запусти сборку после обновления, чтобы подготовить компонент; уже
работающая игра без компонента получит его только после перезапуска.

| Minecraft и загрузчик | Компонент | Выбор без выхода из мира |
| --- | --- | --- |
| NeoForge 1.21.1 | Quick Skin 5.0.2 + Architectury API 13.0.12 (или уже установленный совместимый 13.0.x ≥ 13.0.6) | Esc → **Сменить скин (Change Skin)**, PNG из гардероба |
| Fabric/Forge с выпуском в `launcher/skin_sync_catalog.json` | Skinss+ | **`/skinss`**, выбор PNG |
| Остальные сочетания и Vanilla | Селектор не подключается | Интерфейс сообщает об отсутствии поддержки |

При добавлении, выборе и удалении сохранённого скина лаунчер синхронизирует
PNG с уже подготовленными сборками. Quick Skin перечитывает свой каталог;
для Skinss+ переоткрой меню. Кнопка **Надеть** в лаунчере сохраняет выбор для
следующего запуска; для смены прямо сейчас выбери PNG в игровом меню.
Перезаписывать JSON работающего мода для имитации немедленной смены не требуется.

При следующем запуске лаунчер меняет стартовый скин только если его собственный
выбор PNG/модели изменился. В остальных случаях сохраняется выбор из игры.
Принадлежащие пользователю PNG и настройки не удаляются. Удалённый из гардероба
скин сохраняется на время работающей игры и пока он выбран в игровом меню.
Варианты Classic и Slim с одинаковыми видимыми пикселями имеют отдельные записи
модели. Ошибка косметической подготовки попадает в уведомления и не блокирует игру.

### Что видят другие игроки

На своём клиенте скин меняется сразу. Для передачи нового выбора Quick Skin
нужен совместимый Quick Skin у получателя и на игровом сервере или LAN-хосте,
поддержанный сетевой протокол и разрешающие настройки сервера. Если сервер не
поддерживает его протокол, смена остаётся локальной. Для обмена через Skinss+
также нужен его компонент на серверной стороне и у игроков.

Игровой выбор не отправляется обратно в сервис скинов BlockHarbor. Друг,
у которого есть только CustomSkinLoader, продолжает получать PNG, опубликованный
лаунчером перед запуском. Поэтому наличие общего источника CSL само по себе
не гарантирует немедленного обмена выбором игрового гардероба.

### Официальные файлы и распространение

Quick Skin и Architectury загружаются только при подготовке запуска с
официального CDN Modrinth; размер и SHA-512 закреплены в `game_wardrobe.py`.
Сохранение профиля и опрос интерфейса ничего не скачивают. Несовместимый или
дублирующий установленный мод сохраняется, а пользователю сообщается причина
недоступности селектора.

По [лицензии Quick Skin](https://github.com/The-Plum-Team/Quick-Skin-Mod/blob/573e5f685a80099d48620b407d87ffe0d1c94d74/LICENSE)
его JAR не входит в лаунчер и не переупаковывается в ZIP сборки. Поддержанный
проверенный выпуск восстанавливается из официального источника при первом
запуске импортированной сборки. Пользовательские настройки и PNG не публикуются.

Первичные источники проверенной интеграции:

- [Quick Skin 5.0.2 для NeoForge 1.21.1](https://modrinth.com/mod/quick-skin/version/Y863HK0w).
- [Обновление списка PNG и применение выбора в игровом меню](https://github.com/The-Plum-Team/Quick-Skin-Mod/blob/573e5f685a80099d48620b407d87ffe0d1c94d74/modules/skin-menu/src/main/java/com/quickskin/mod/client/gui/screen/PlayerSkinMenuScreen.java).
- [Проверка сетевого протокола сервера](https://github.com/The-Plum-Team/Quick-Skin-Mod/blob/573e5f685a80099d48620b407d87ffe0d1c94d74/modules/networking/src/main/java/com/quickskin/mod/networking/NetworkSyncService.java).
- [Выбор скина для точного UUID и имени учётной записи](https://github.com/The-Plum-Team/Quick-Skin-Mod/blob/573e5f685a80099d48620b407d87ffe0d1c94d74/modules/configuration/src/main/java/com/quickskin/mod/config/AccountSkinPreferences.java).

## Имена и официальные профили

Локальный ник не является подтверждённой учётной записью Microsoft. Первый лаунчер, опубликовавший скин для свободного ника, получает право менять эту запись своим случайным ключом. Другой лаунчер не может перезаписать занятый ник: ошибка появляется в истории уведомлений, локальный PNG продолжает работать. У каждого локального ника свой ключ, поэтому несколько одновременно открытых лаунчеров не заменяют скины друг друга. После смены ника новый скин публикуется отдельно, а прежняя запись остаётся доступной уже запущенной игре и истекает после 30 дней без использования. Переустановка с удалением всех данных теряет этот ключ. Это косметическая запись, а не система аутентификации игры.

В режимах Microsoft/Prism сохраняется приоритет официального источника Mojang для других игроков. Лаунчер не публикует неподтверждённую запись от имени Microsoft-профиля. Для официального скина используется профиль Minecraft. Собственный сохранённый локальный PNG по-прежнему может отображаться на этом компьютере.

## Сеть и хранение

Ключ владельца хранится только в локальной базе лаунчера и не входит в ZIP сборки, публичный JSON или адрес текстуры. Сервис хранит SHA-256 ключа, ник, пиксели и модель, а для ограничения частоты — HMAC сетевого адреса с серверным секретом. Сырой IP не сохраняется.

Сервис принимает обычный RGBA PNG 64×64 размером не более 24 КиБ, проверяет структуру, CRC и ограниченный объём распакованных пикселей. Произвольные URL и чтение файлов не поддерживаются. Изменение и удаление требуют ключа владельца. Установлены ограничения частоты, количества записей с одной сети и общий предел 5000 профилей. Пиксели и метаданные записываются атомарно в D1; временное R2-хранилище сборок не используется.

Неизменный скин повторно подтверждается не чаще раза в десять минут; смена ника, PNG или модели отправляется сразу. Клиент делает одну попытку с сетевым таймаутом шесть секунд, затем продолжает запуск игры. Ошибка не подменяется сообщением об успешном обмене. Повтор после ошибки ограничен минутой. Без посещений запись доступна 30 дней, затем перестаёт выдаваться и удаляется при следующей публикации. Доступность новых общих скинов зависит от доступа клиента к сервису; локальный скин и доступный кэш остаются пригодны при сетевой ошибке.

## Сервер

Перед развёртыванием `skin-registry.mjs` нужно применить миграцию `0004_skin_registry.sql`. `GET /v1/skins/capabilities` подтверждает наличие таблиц и серверного секрета. Публичный интерфейс:

- `GET /v1/skins/{Nickname}.json`: профиль CustomSkinAPI, включая модель `default`/`slim`.
- `GET /v1/skins/textures/{sha256}`: только проверенные PNG из действующих записей.
- `PUT /v1/skins/profile/{Nickname}`: собственный PNG с `Authorization: Bearer …` и `X-Skin-Model`.
- `DELETE /v1/skins/profile/{Nickname}`: удаление собственной записи.

Протокол соответствует [официальной реализации CustomSkinAPI](https://github.com/xfl03/MCCustomSkinLoader/blob/15-develop/Common/src/main/java/customskinloader/loader/jsonapi/CustomSkinAPI.java). Ограничение локального источника описано в [руководстве CustomSkinLoader](https://github.com/xfl03/MCCustomSkinLoader/wiki/How-to-Use). Условия серверного обмена Skinss+ приведены на [странице автора](https://modrinth.com/mod/skinss-plus).
