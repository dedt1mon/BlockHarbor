# BlockHarbor 2.6.6 — исправления установщика, запуска и каталога

## Установщик
- Исправлена кодировка NSIS: исходные русские строки всегда передаются компилятору в UTF-8 с BOM и явно заданным INPUTCHARSET UTF8. Локаль сборочной машины не влияет на кириллицу.
- Добавлена проверка русского поля FileDescription готового EXE, реальной тихой установки в путь с кириллицей, тихого обновления и удаления на Windows CI.
- Сборки, миры и настройки сохраняются при обычном обновлении; тихое удаление по-прежнему не удаляет личные данные.

## Запуск лаунчера
- Microsoft Edge больше не является основным или обязательным браузером. Приоритет: Chrome, Brave, Chromium, Vivaldi, Firefox, затем необязательный Edge. При ошибке запуска пробуется следующий доступный браузер.
- Отдельный профиль для каждого браузерного продукта защищает его обычные вкладки и настройки. Сохранена существующая логика регистрации, скрытия и восстановления окна при игре.
- Если отдельный совместимый браузерный процесс недоступен, используется браузер по умолчанию. Встроенный HTML-интерфейс по-прежнему требует браузерного движка; он не был заменён на новый нативный GUI.

## Каталог и общая надёжность
- Исправлены показ просроченной публикации из кэша и округление оставшегося времени блокировки.
- Серверный endpoint возможностей теперь не сообщает о готовности новой политики, если не настроены необходимые привязки, миграция D1 или серверный секрет.
- Расширены проверки: Python-регрессия, JavaScript, жизненный цикл окна, серверный контракт каталога, реальная установка и локальный API упакованной программы на Windows.

**Ограничение:** сервер каталога не развёртывается обновлением EXE. Активация серверных лимитов, часового удаления и пятичасовых запретов всё ещё требует обновления действующего облачного обработчика (GitHub Issue #2). Не менялись публикации, данные игроков и права доступа к действующему хостингу.
