# Модпаки и сборки для друзей

## Готовые сборки Modrinth

В разделе **Каталог сборок** можно искать готовые сборки по названию, версии
Minecraft, загрузчику и категории. Сортировка поддерживает релевантность,
число загрузок, число подписчиков, новые и недавно обновлённые проекты.
Страница результатов остаётся на экране, пока загружается следующая;
выбранный выпуск проекта сохраняется отдельно от страницы поиска.

После выбора выпуска BlockHarbor сначала загружает и проверяет `.mrpack`,
показывает версию Minecraft, точную версию загрузчика, объём загрузки и список
необязательных файлов. Пользователь выбирает необязательные компоненты сам.
Файлы, помеченные автором как несовместимые с клиентом, пропускаются.

Кнопка **Импорт .mrpack** открывает такой же предварительный просмотр для
файла на компьютере. Обычный формат ZIP BlockHarbor остаётся доступным.
При первой установке лаунчера список сборок пуст: каталог ничего не
устанавливает без выбора пользователя.

### Проверки и публикация сборки

- `modrinth.index.json` проверяется до распаковки и скачивания.
- Файлы загружаются только по HTTPS с разрешённых серверов Modrinth,
  GitHub и GitLab. Эти же ограничения применяются к перенаправлениям.
- Каждый скачанный файл должен совпасть с указанными размером, SHA-1
  и SHA-512.
- Проверяются выходы за пределы папки, символические ссылки, имена Windows,
  конфликты регистра/Unicode, повторяющиеся файлы и совпадения файла с папкой.
- Лимиты: 2 ГБ на архив `.mrpack`, 8 ГБ на данные сборки,
  512 МБ на отдельный файл, 20 000 файлов и 8 МБ на индекс.
- Сначала применяются `overrides`, затем `client-overrides`.
  `server-overrides` не устанавливаются на клиент.
- Незавершённая установка не появляется в списке сборок. При ошибке временная
  папка новой сборки удаляется, а ранее выбранная сборка остаётся выбранной.

Модпак закрепляет Minecraft и версию Fabric, Quilt, Forge или NeoForge.
Неизвестная обязательная зависимость формата вызывает понятную ошибку,
а не молчаливую установку неподходящей игры.

## Выгрузка .mrpack

Кнопка **Выгрузить .mrpack** создаёт стандартный архив. Дополнения,
опознанные по хешу на Modrinth, записываются в индекс как проверяемые загрузки.
Локальные файлы включаются в `overrides`. Фильтрация личных настроек такая же,
как при обычной выгрузке ZIP BlockHarbor. Миры, учётные записи и журналы в
`.mrpack` не включаются.

Перед первой выгрузкой сборки с загрузчиком нужно один раз запустить её:
это фиксирует точную версию загрузчика. Обычный ZIP можно выгрузить и раньше.

## Сравнить состав со сборкой друга

1. Хозяин выбирает сборку, открывает **Друзья → Поделиться составом** и
   передаёт другу файл `.bhshare` или код `bhshare:…`.
2. Друг нажимает **Сравнить со сборкой друга**, выбирает файл или вставляет код.
3. Лаунчер показывает совпадающие файлы, недостающие моды, другие версии,
   личные клиентские компоненты и файлы без доступного источника.
4. **Подготовить отдельную сборку** сохраняет исходную сборку. Для одинаковой
   версии игры можно также применить изменения к текущей сборке; перед этим
   создаётся точка восстановления.

Код содержит само описание сборки. Для его передачи не нужен сервер
BlockHarbor. Это не короткий адрес облачного хранилища: большой состав модов
может дать длинный код, для которого удобнее файл `.bhshare`.

Точные хеши сравниваются независимо от переименования JAR. Если сторона
работы мода не объявлена, мод сравнивается как обязательный, а интерфейс
объясняет неопределённость. Моды, явно обозначенные как клиентские, не
навязываются друзьям. Личные клиентские дополнения и параметры исходной
сборки сохраняются. Миры в копию для синхронизации автоматически не переносятся.

Если источника скачивания нет, лаунчер перечисляет нужные файлы и предлагает
получить обычный ZIP сборки или добавить файлы вручную. Сходство названий
не используется как основание скачать случайный мод. Совпадение файлов
само по себе не подтверждает совместимость всех игровых конфигураций.

## Приглашение в мир

Хозяин открывает мир через e4steam в Minecraft и вставляет текущий зелёный
адрес `s-…-….steam` в **Приглашение в мир**. Полученный код включает адрес
сеанса и описание сборки. После сравнения состава гость может добавить мир
в список серверов Minecraft одной кнопкой.

`servers.dat` изменяется только при закрытой игре, с сохранением существующих
серверов и неизвестных NBT-полей. Предыдущий файл сохраняется рядом как
`.blockharbor-servers.bak`. Кнопка не принимает произвольные веб-адреса.

Адрес действует только для текущего сеанса e4steam. Steam продолжает проверять
доступ; режим «Только по приглашению» дополнительно требует приглашения
через Steam. Создание/открытие самого мира и подтверждение входа выполняются
в Minecraft. Игра не остаётся на сервере BlockHarbor после закрытия мира.

О живом статусе текущего сеанса см. [Компонент статуса](room-status-bridge.md).
