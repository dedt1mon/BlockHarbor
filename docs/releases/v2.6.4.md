## BlockHarbor 2.6.4 — сборки игроков без обязательного VPN

### Доступность общего каталога

- Если основной каталог сборок игроков не отвечает из-за сетевой блокировки, HTTP 403 или временной ошибки сервера, лаунчер автоматически переключается на независимое **публичное зеркало в GitHub Releases**.
- Резервный канал поддерживает **поиск по названию и ID**, фильтры Minecraft/загрузчика/категории и установку сборок со своей копией файлов.
- ZIP-архив каждой сборки загружается из GitHub только после проверки метаданных. При установке сверяются размер и SHA-256, как и раньше.
- Зеркало синхронизируется примерно каждые пять минут и удаляет снятые с публикации архивы при следующем успешном обновлении. При сбое синхронизации устаревшие более двух часов данные не показываются.
- Если основной сервер доступен, используется он. Публикация и удаление публикаций по-прежнему обращаются к основному серверу, чтобы не создавать два независимых каталога.
- Зеркало хранит только публичные описания и публичные ZIP-файлы; токены авторов, локальные журналы и миры не копируются.

### Интерфейс

- Заголовок **«Модпаки Modrinth»** переименован в **«Модпаки»**.
- При подключении к резервному каталогу выводится ненавязчивое уведомление.
- Уменьшено ожидание сетевого ответа при поиске, если основной сервер недоступен.

**Важно:** доступность GitHub тоже может различаться по провайдерам; универсальную работу из всех сетей гарантировать нельзя.

Установка: `BlockHarbor-Setup-2.6.4.exe`. Обновление совместимо с предыдущей стабильной версией.
