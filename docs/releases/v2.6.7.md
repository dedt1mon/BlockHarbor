# BlockHarbor 2.6.7 — установка модов и единый интерфейс

- При выборе модов из каталога учитывается, что один выпуск может содержать несколько JAR-файлов для разных загрузчиков. Приоритет получает подходящий исполняемый файл; файлы исходного кода, документации и разработки не предлагаются для установки.
- Если основной JAR не содержит метаданных для выбранного загрузчика, проверяются альтернативные файлы **того же выпуска**, доступные из разрешённых источников. Размер и SHA-512 проверяются для каждого скачанного файла. Ошибки контрольной суммы, транспорта или повреждённого архива не обходятся альтернативной загрузкой.
- Добавлена поддержка FML-библиотек и языковых провайдеров Forge/NeoForge, явно указанных в основном разделе манифеста JAR. Произвольные JAR без метаданных и файлы с несовместимыми маркерами по-прежнему отклоняются.
- Групповая установка сохраняет атомарность: если совместимый файл не найден, моды из этой операции не записываются в сборку, а сообщение содержит имя проблемного файла и выбранный загрузчик.
- При повторной установке учитываются уже установленные проверенные альтернативные файлы. Поиск обязательных зависимостей и подтверждение предупреждений используют действительно выбранный файл и его контрольную сумму.
- Тот же механизм используется для проверяемого плана обновления дополнений.

Локальные сборки, миры и существующие файлы не удаляются и не заменяются при неудачной проверке. Совместимость конкретного мода с конкретной сборкой по-прежнему зависит от его авторов и доступных выпусков. Новые серверные функции каталога игроков не активируются этим клиентским обновлением.


## Единый стиль интерфейса

- Общая высота обычных полей и кнопок — 44 px, компактных кнопок — 36 px. Согласованы радиусы, цвет рамки и фон полей поиска, текстовых и числовых полей, списков выбора.
- У полей больше нет разных локальных рамок при фокусе. Единое внутреннее выделение без изменения размеров; клавиатурный фокус и предупреждения остаются различимыми.
- Активные вкладки, выбранные сборки, моды и скриншоты используют согласованную зелёную подсветку. Убраны дублирующиеся рамки и тени выбора.
- Исправлены узкие окна, перенос длинных названий, сетки полей, расположение кнопок в настройках и каталогах, числовые поля резервного копирования.
- Добавлена проверка вычисленных размеров, фокуса, выбора и отсутствия горизонтального переполнения на представительном наборе элементов интерфейса в Chromium при трёх размерах окна.
