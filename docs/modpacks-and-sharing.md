# Модпаки и сборки для друзей

## Готовые сборки Modrinth

В модальном окне **Сборки → Каталог сборок** можно искать готовые сборки по названию, версии
Minecraft, загрузчику и категории. Сортировка поддерживает релевантность,
число загрузок, число подписчиков, новые и недавно обновлённые проекты.
Страница результатов остаётся на экране, пока загружается следующая;
выбранный выпуск проекта сохраняется отдельно от страницы поиска.

После **Выбрать выпуск → Подготовить установку** BlockHarbor загружает,
проверяет и устанавливает `.mrpack` сразу, без дополнительного диалога.
Название и закреплённые Minecraft/загрузчик берутся из архива. Обязательные
компоненты устанавливаются, необязательные и несовместимые с клиентом файлы
пропускаются. Возможность игры без встроенного Steam-соединения объясняется
под выбором выпуска; повторного подтверждения для этого пути нет.

Для файла сборки на компьютере используй **Сборки → Загрузить сборку** и ZIP BlockHarbor. Кнопка локального импорта `.mrpack` удалена из каталога в 2.4.8; готовые модпаки устанавливаются через поиск Modrinth.

Подтверждение продолжения без Steam сохраняется для установленной сборки; при следующих запусках повторять его не нужно. Доступность самой версии Minecraft, загрузчика и подходящей Java проверяется отдельно.

При первой установке лаунчера список сборок пуст: каталог ничего не
устанавливает без выбора пользователя.

### Проверки при установке

- `modrinth.index.json` проверяется до распаковки и скачивания.
- Файлы загружаются только по HTTPS с разрешённых серверов Modrinth,
  GitHub и GitLab. Эти же ограничения применяются к перенаправлениям.
- Каждый скачанный файл должен совпасть с указанными размером, SHA-1
  и SHA-512.
- Проверяются выходы за пределы папки, символические ссылки, имена Windows,
  конфликты регистра/Unicode, повторяющиеся файлы и совпадения файла с папкой.
- Лимиты: 2 ГБ на архив `.mrpack`, 8 ГБ на данные сборки,
  512 МБ на отдельный файл, 20 000 файлов и 8 МБ на индекс.
- Сначала применяются `overrides`, затем `client-overrides`.
  `server-overrides` не устанавливаются на клиент.
- Незавершённая установка не появляется в списке сборок. При ошибке временная
  папка новой сборки удаляется, а ранее выбранная сборка остаётся выбранной.

Модпак закрепляет Minecraft и версию Fabric, Quilt, Forge или NeoForge.
Неизвестная обязательная зависимость формата вызывает понятную ошибку,
а не молчаливую установку неподходящей игры.

## Публикация сборок временно отключена

Начиная с 2.6.16 функция **Поделиться** временно недоступна. Кнопка и окно
публикации убраны, запросы каталога пользовательских публикаций и их установка
не выполняются. Существующие серверные публикации не снимаются принудительно;
прежний срок хранения остаётся в силе.

Каталог готовых модпаков Modrinth работает. Для файла сборки на компьютере
доступны отдельные **Выгрузить** и **Загрузить сборку**, описанные ниже.
Сервис общих скинов работает независимо от отключённой публикации сборок.

## Формат обмена

Для передачи своей сборки используется ZIP BlockHarbor. Кнопки **Выгрузить**
и **Загрузить сборку** находятся в разделе **Сборки**. Каталог Modrinth сам
скачивает и проверяет `.mrpack` выбранного проекта перед установкой.

## Передать сборку другу

В разделе **Сборки** нажми **Выгрузить** в строке нужной сборки. В архив
входят версия игры, закреплённый загрузчик, дополнения и совместимые настройки,
без сохранённых миров. Передай файл выбранным способом. Друг открывает
**Сборки → Загрузить сборку** и выбирает ZIP; создаётся отдельная копия сборки.

Блок **Передать другу ZIP** из окна публикации удалён в 2.6.16. Отдельный
экспорт и импорт файлов не требуют сервера публикаций.

Начиная с 2.6.18 обычная выгрузка добавляет доступный проверенный установщик
NeoForge и сохранённые библиотеки его подготовки. Для старой локально установленной
сборки лаунчер предварительно пытается сохранить её точный установщик, если он
отсутствует в кеше. Уведомление о готовом ZIP сообщает, включены ли файлы NeoForge.
Получатель независимо проверяет их перед переносом в общий кеш. Для такого
архива у получателя нужна 2.6.18 или новее; старые обычные ZIP продолжают работать.

В Windows-поставке 2.6.19 для точной пары Minecraft 1.21.1 / NeoForge 21.1.267
установщик и необходимые сторонние библиотеки также находятся внутри приложения.
Выгрузка может взять их оттуда без обращения к сети и без установочного кеша
отправителя. Получатель с 2.6.19 использует этот комплект и для старого обычного
ZIP: тайм-ауты Maven и ForgeCDN не требуют повторной передачи сборки.
Новая выгрузка с комплектом также включает соответствующие исходники и лицензии
отдельными непрозрачными документами. Такой ZIP третьего формата требует
BlockHarbor 2.6.19 или новее; импорт первого и второго форматов сохранён.
Исходники из архива не запускаются и не копируются в библиотеки игры.

Java, клиент Minecraft, ресурсы и библиотеки Mojang в ZIP не входят. При первом
запуске на чистом компьютере лаунчер получает их из официальных источников.
Проверенные файлы сохраняются между попытками; завершённая установка той же версии
может использоваться другой импортированной сборкой после проверки. При ошибке
загрузки можно сначала обновить лаунчер у получателя и повторить **Играть** в
существующей сборке. Для встроенной точной версии повторная выгрузка не нужна.
Для передачи сохранённых файлов других NeoForge можно выгрузить новый ZIP;
удалять миры и все данные лаунчера не нужно.

Проверенный Quick Skin 5.0.2 для NeoForge 1.21.1 не включается в архив согласно
[лицензии автора](https://github.com/The-Plum-Team/Quick-Skin-Mod/blob/573e5f685a80099d48620b407d87ffe0d1c94d74/LICENSE).
Он автоматически загружается с официального источника при первом запуске
импортированной сборки через BlockHarbor 2.6.15 или новее. Для иной версии или отключённого
Quick Skin экспорт объясняет необходимость официального способа распространения,
не подменяя выбранный мод. Личные настройки Quick Skin, предпочтения моделей
и PNG гардероба в ZIP не попадают; исходные файлы остаются на компьютере автора.

Начиная с 2.4.1 блок ручного сравнения и обмена описанием `.bhshare` удалён
из интерфейса Друзей. Ранее сохранённые пользовательские файлы не удаляются.

## Игра с друзьями

В разделе **Друзья** доступны открытие Steam и инструкции подключения.
Хозяин открывает одиночный мир для сети через e4steam и приглашает друга
в оверлее Steam. Гость запускает свою сборку и принимает приглашение.
Версии Minecraft, загрузчика и обязательных модов у участников должны совпадать.

При прямом подключении используется текущий зелёный адрес `s-…-….steam`
из Minecraft. После повторного открытия мира адрес нужно получить заново.
Доступ к сеансу проверяет Steam; режим «Только по приглашению» требует
приглашения через Steam. Создание мира и подтверждение входа выполняются в игре.
