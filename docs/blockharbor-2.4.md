# BlockHarbor 2.4: подготовка без консоли и обновления при ограничении GitHub

## Что видно в лаунчере

При подготовке Java, файлов Minecraft, загрузчика и дополнений текущий этап
появляется в уведомлении справа снизу. Загрузка обновления BlockHarbor также
использует это уведомление. После завершения или ошибки результат ненадолго
остаётся на экране; подробности загрузок доступны в настройках.

Служебная консоль больше не создаётся ни загрузчиком приложения, ни механизмом
подготовки игры. Вывод установщиков загрузчиков остаётся доступен для обработки
ошибок. Отмена и завершение принадлежащих окну служебных процессов сохраняются.

При самом первом запуске приложение должно распаковать встроенную среду до
запуска интерфейса. Этот этап выполняется без консоли и записывается в журнал
запуска. После открытия окна отображается сообщение о завершении подготовки.

## Что исправлено в проверке обновлений

`HTTP Error 403: rate limit exceeded` означает, что GitHub ограничил запросы
к API. Лаунчер учитывает указанный сервером срок следующей попытки и временно
получает информацию из публичных файлов того же репозитория. В стабильном
канале используется последний стабильный релиз; тестовый канал учитывает
предварительные выпуски.

Несколько открытых окон используют общий кэш обнаружения релизов и общий срок
ожидания. Повторное нажатие проверки не создаёт отдельные одинаковые запросы.
Кэш содержит метаданные релизов, а не токены или учётные данные GitHub.

Резервный источник не отменяет проверок установщика: разрешены только адреса
нужного репозитория и домены доставки GitHub, проверяются размер, SHA-256 и
совместимость формата данных. Новый манифест выпуска содержит имя, размер и
хеш установщика; его прежние поля остаются совместимыми с 2.2 и 2.3.

## Как перейти с 2.3

Если проверка обновлений работает, оставь одно окно лаунчера открытым, заверши
игры и загрузки и дождись обычного автоматического обновления. Переключатель
находится в **Настройки → Загрузки и обновления**.

Если в 2.3 уже действует ошибка лимита, скачай `BlockHarbor-Setup-2.4.0.exe`
из [релиза 2.4.0](https://github.com/dedt1mon/BlockHarbor/releases/tag/v2.4.0).
Закрой игры и лаунчер и установи его в прежнюю папку. Удалять приложение заранее
не требуется. Сборки, миры, скины и настройки сохраняются. Исправленный резервный
механизм начнёт работать после этого обновления.

## Проверка

Регрессионные тесты покрывают скрытый запуск служебных процессов, передачу
прогресса, лимит API и срок повторной попытки, общий кэш нескольких окон,
резервное обнаружение релиза и отклонение неверных метаданных. Сборка Windows
проверяется по ресурсам EXE, встроенным исходникам и содержимому установщика.
Linux-проверки не заменяют испытание появления окон и установки на Windows.
