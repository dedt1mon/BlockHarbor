# BlockHarbor 2.6.13

Лаунчер Minecraft Java Edition для Windows 11 x64 с установщиком и собственной иконкой зелёного куба. В одном окне можно выбрать сборку, настроить персонажа и запустить Minecraft для игры с друзьями через Steam. Исходный код входит в комплект. В BlockHarbor нет рекламных блоков, аналитических SDK и платных функций.

## Что изменилось в 2.6.13

- В настройках появилась вкладка «Улучшения и поддержка»: Telegram, сайт автора и добровольный перевод по номеру карты с выбором суммы от 50 ₽. Кнопка возврата версии убрана.
- Убраны лишние пояснения в профиле и друзьях. Кнопка «Проверить подключение» заменена на «Скачать Steam».
- «Подготовить установку» в каталоге сразу устанавливает выбранный выпуск в отдельную сборку без промежуточных окон.
- В каталоге дополнений убраны внешние поисковые ссылки, нижняя навигация выровнена. Встроены Modrinth и проверенные GitHub-релизы; подключение CurseForge и Planet Minecraft ожидает необходимого доступа.
- В «Ошибках сборки» добавлена кнопка «Очистить»: удаляются показанные записи этой сборки, игровые логи и новые события сохраняются.
- [Полное описание](docs/releases/v2.6.13.md).

## Установка и первый запуск

1. Скачай **BlockHarbor-Setup-2.6.13.exe** из [релиза](https://github.com/dedt1mon/BlockHarbor/releases/tag/v2.6.13) и открой двойным щелчком. Мастер установки работает на русском языке.
2. Выбери папку приложения. По умолчанию используется `%LOCALAPPDATA%\Programs\BlockHarbor` для текущего пользователя Windows.
3. Отметь **Создать ярлык на рабочем столе**, если он нужен. Установщик также добавит BlockHarbor в список приложений меню **Пуск**. Можно отдельно выбрать помощь с закреплением на панели задач и на начальном экране. После установки мастер покажет инструкции и предложит открыть установленный ярлык в Проводнике; само закрепление подтверждается через меню Windows.
4. Заверши установку и открой BlockHarbor через ярлык. Встроенный пакет включает Python, библиотеки и интерфейс. Первая распаковка выполняется без консоли; после открытия интерфейса результат подготовки сохраняется в истории уведомлений. До распаковки встроенной среды интерфейс ещё не запущен.
5. Открой **Профиль**, задай **Ник в игре** и нажми **Сохранить все параметры**. Создавать сборку для этого не требуется.
6. На чистой установке список сборок пуст. Готовый модпак можно самостоятельно выбрать в **Сборки → Каталог сборок**. Нажми **Новая сборка**, выбери Minecraft и доступный для него загрузчик или нажми **Загрузить сборку**, чтобы импортировать ZIP друга. Для снапшотов, старых бета-версий и ранних выпусков включи **Показывать снапшоты и старые версии**.
7. Выбери сборку и нажми **Играть** на главной. Локальный профиль использует сохранённый общий ник. Для выбранной версии лаунчер автоматически подготовит Java, файлы Minecraft, загрузчик и поддерживаемые сетевые компоненты. Первой загрузке нужен интернет. Во время подготовки виден текущий этап.

Когда подготовка закончится, откроется Minecraft. Последующие запуски используют установленные компоненты. Иконка зелёного куба встроена в EXE, установщик и программу удаления. Ярлыки Windows используют эту иконку.

### Обновление и удаление

Для перехода с 2.2, 2.3, 2.4, 2.4.1, 2.4.2, 2.4.3, 2.4.4, 2.4.5, 2.4.6, 2.4.7, 2.4.8, 2.4.9, 2.4.10, 2.4.11, 2.5.0 или 2.5.1 оставь одно окно лаунчера открытым и заверши игры и загрузки. Версия 2.6.0 устанавливается автоматически, если включено **Настройки → Загрузки и обновления → Автоматически обновлять BlockHarbor**. Проверка выполняется при запуске и каждые 10 минут открытого сеанса. Установка ждёт завершения игр, загрузок, операций и закрытия остальных окон, затем обновляет прежнюю папку приложения и открывает одно окно. При выключенном переключателе доступны ручные проверка, скачивание и установка. Если в старой версии проверка при запуске была отключена, этот отказ сохраняется.

Если в 2.3 уже появилась ошибка `HTTP Error 403: rate limit exceeded`, скачай актуальный установщик, закрой лаунчер и игры и установи обновление в прежнюю папку. Сборки, миры, скины и настройки сохранятся. Старый код проверки не получает новое исправление до установки новой версии; автоматический переход также возможен после восстановления лимита GitHub.

Обычный крестик завершает лаунчер и отменяет его текущие операции, включая ожидающее автообновление. Сворачивание или автоматическое скрытие во время Minecraft оставляет открытый сеанс работающим. Уже запущенные игры и другие окна лаунчера не завершаются принудительно. После ручного закрытия скрытый процесс проверки обновлений не остаётся.

Перед обновлением сохраняется предыдущий исполняемый файл для совместимого отката приложения. Откат приложения и откат сборки — отдельные действия. Установщик использует зарегистрированную папку приложения. Игровые данные находятся в `%LOCALAPPDATA%\BlockHarbor`.

Для удаления приложения открой **Параметры Windows → Приложения → Установленные приложения → BlockHarbor → Удалить** или **Пуск → BlockHarbor → Удалить BlockHarbor**. Мастер предложит удалить только приложение или приложение вместе со всеми его локальными данными. По умолчанию сборки, миры и настройки сохраняются. При выборе полной очистки удаляются данные в `%LOCALAPPDATA%\BlockHarbor`, включая сборки, миры, копии, скины, снимки, настройки и кэши. Перед полной очисткой нужно завершить игры и все окна лаунчера.

Программа распаковывает свои рабочие файлы в отдельный каталог внутри `%LOCALAPPDATA%\BlockHarbor\app`. При потере или изменении установленных компонентов следующий запуск EXE восстанавливает их из встроенного пакета. Новая версия программы получает отдельный каталог. Миры находятся в каталогах сборок.

При обычном открытии размер окна составляет примерно 1360×840 при масштабе 100 %. На небольшом дисплее начальный размер подстраивается под доступную область экрана. Окно можно развернуть на всю рабочую область монитора кнопкой **Развернуть** в заголовке или двойным щелчком по заголовку, свободно растянуть за края либо закрепить средствами Windows. Интерфейс занимает всю область окна, а длинные страницы прокручиваются. В Windows лаунчер открывает отдельное окно через Edge, Chrome, Brave или Firefox. При открытии во вкладке браузера интерфейс также заполняет её доступную область.

Сборки Fabric и Forge 1.20.1 поддерживают игру через Steam и автоматический обмен скинами в общем мире. Создай такую сборку самостоятельно или импортируй ZIP, который выгрузил друг. Карту и сид выбирай в игре. BlockHarbor предназначен для владельцев Minecraft Java Edition. Файлы игры загружаются при первой установке.

После подготовки файлов и запуска Minecraft связанное окно BlockHarbor автоматически скрывается и возвращается после завершения своих игровых сеансов. При ошибке запуска или аварийном выходе сообщение можно прочитать в лаунчере. Повторное открытие `BlockHarbor.exe` создаёт ещё одно окно: в нём можно выбрать другую сборку и запустить ещё один Minecraft. Для нескольких экземпляров одного набора модов заранее создай отдельные копии сборки. В режиме Microsoft через Prism настройка аккаунта проходит с открытым окном BlockHarbor. Автоматическое скрытие в Windows работает в отдельном окне Edge, Chrome, Brave или Firefox.

## Профиль игрока

По умолчанию BlockHarbor напрямую запускает Minecraft с локальным ником. Такой профиль подходит для одиночной игры и сервера, принимающего локальные профили. В одиночном мире смена локального ника меняет UUID персонажа, и игра может открыть отдельный инвентарь.

Для сервера с проверкой Microsoft выбери **Настройки → Профиль запуска → Microsoft через Prism**, нажми **Сохранить настройки** и вернись к кнопке **Играть**. При первом использовании следуй подсказкам для входа в Microsoft-аккаунт с Java Edition. После настройки сборка запускается из BlockHarbor той же кнопкой.

## Ник и скин

В **Гардеробе** можно сохранить уже применённый скин под своим названием и выбрать его перед следующим входом. Если меняешь файл или модель в предпросмотре, сначала сохрани параметры профиля.

1. Открой **Профиль** и укажи **Ник в игре**: от 3 до 16 латинских букв, цифр или символов подчёркивания. Ник можно сохранить до создания первой сборки. Его редактирование находится только в профиле.
2. При желании нажми **Выбрать скин игрока** и открой свой PNG. Для 64×64 выбери модель **Classic** или **Slim**; для 64×32 подходит **Classic**.
3. Нажми **Сохранить все параметры** и дождись сообщения **Успешно сохранено**. Общий профиль сохранится независимо от наличия, версии и загрузчика сборки. Настройки действуют при следующем запуске игры; уже запущенная игра продолжает использовать прежний профиль.
4. Создай, импортируй или выбери сборку и нажми **Играть** на главной. Ник используется во всех сборках с локальным профилем, а сохранённый скин автоматически применяется там, где доступен совместимый загрузчик скинов. В игре нажми F5 или открой инвентарь, чтобы увидеть персонажа.

Если для выбранной Vanilla-сборки доступен Fabric, можно отдельно отметить **Установить Fabric для скина в выбранной сборке** и подтвердить переход. Он сохраняет версию Minecraft и миры; для установки компонентов закрой эту сборку в Minecraft.

**Чтобы друзья увидели локальные скины**, обновите BlockHarbor у всех участников и заново запустите игру через лаунчер. Для совместимых Fabric, Quilt, Forge и NeoForge, включая NeoForge 1.21.1, автоматически устанавливается CustomSkinLoader и настраивается общий источник скинов BlockHarbor. Выбранный PNG и модель передаются в сервис перед запуском, друзья получают их по игровому нику. Нужный компонент ставится и игрокам без своего PNG; отдельная установка мода на игровом сервере не требуется.

Vanilla без загрузчика модов не использует этот механизм. В режиме Microsoft для других игроков сохраняется приоритет официального Java-профиля. Игрокам с другим лаунчером требуется совместимо настроенный CustomSkinLoader. Ошибка сервиса общих скинов не блокирует запуск игры и сохраняется в истории уведомлений. Старый Skinss+ остаётся дополнительным способом для поддерживаемых миров. [Как устроен обмен скинами](docs/skins-and-sharing.md).

**Для Vanilla и серверов с официальными скинами** выбери PNG и модель в разделе **Профиль** и нажми **Сохранить все параметры**. Лаунчер сохранит общий ник, PNG и модель на компьютере. Затем открой **Установить скин в Java-профиле → Скачать мой PNG**. Нажми **Открыть Minecraft.net**, войди в свой аккаунт с Java Edition, выбери модель и загрузи PNG. Если ты уже вошёл через **Свой Microsoft Client ID**, в лаунчере доступна кнопка **Применить к аккаунту**. Затем войди в Minecraft под этим Java-профилем. На сторонних серверах с собственной системой скинов отображение определяет сервер. [Профиль Minecraft](https://www.minecraft.net/msaprofile/mygames)

## Передать сборку другу

Открой **Сборки** и нажми **Выгрузить** в строке нужной сборки: ZIP начнёт скачиваться после подготовки без дополнительного подтверждения. В архив входят версия игры и загрузчик, установленные моды, шейдеры, ресурс-паки и совместимые файлы настроек. Сохранённые миры в этот ZIP не включаются.

На другом компьютере открой **Сборки → Загрузить сборку** и выбери этот ZIP. Лаунчер создаст и выберет новую сборку. Если такое название уже есть, к новой копии добавится номер. Скины персонажа, данные входа в лаунчер и журналы хранятся отдельно от архива.

При первом запуске существующей или импортированной сборки без совместимого Steam-комплекта это же предупреждение появляется до подготовки файлов игры, если продолжение без Steam для неё ещё не подтверждено. Сам импорт локального ZIP выполняется как прежде.

## Создание сборок и дополнения

Открой **Сборки → Новая сборка**, дай ей название и выбери версию Minecraft и загрузчик. По умолчанию список показывает стабильные релизы Java Edition. Включи **Показывать снапшоты и старые версии**, чтобы открыть снапшоты, бета-версии, альфа-версии и ранние выпуски из официального каталога Mojang. Комплектный снимок содержит 925 записей, из которых 103 — релизы. Исторические названия с пробелами сохраняются без переименования.

Форма читает список загрузчиков с диска сразу при выборе версии. Переключатель снапшотов также использует локальный список. Нажми кнопку обновления в форме, чтобы получить новые сведения от разработчиков. Для старых выпусков Forge сохранены полные имена установщиков. Для архивных выпусков, где нужен ручной патч игрового JAR, форма объясняет это ограничение. Кнопка **Выбрать Vanilla** переключает новую сборку на игру без загрузчика.

Если прежняя попытка установить Fabric закончилась HTTP 400, после обновления проверь выбранную пару Minecraft/загрузчик. Для неподдерживаемой пары создай отдельную сборку Vanilla или выбери доступный загрузчик. Уже установленные сборки используют закреплённый загрузчик и проверенные локальные файлы без обязательного сетевого запроса совместимости при каждом запуске. Временные сетевые ошибки по-прежнему допускают повторные попытки загрузки.

В совместимой сборке BlockHarbor подготовит компоненты для игры через Steam во время создания. Существующая сборка получит их при следующем запуске. Если для выбранных Minecraft и загрузчика нет совместимого комплекта, перед созданием появится окно **Игра без подключения через Steam**. **Продолжить без Steam** сохраняет выбранные версию и загрузчик и продолжает создание без встроенного Steam-соединения; **Отмена** возвращает к выбору без начала загрузки. Подтверждение запоминается для этой сборки, поэтому повторять его при каждом запуске не нужно. Для обычной игры без модов выбери **Vanilla**.

Поддержка Steam и доступность самой игры или загрузчика проверяются отдельно. Наличие версии в списке Minecraft не означает, что для неё существует любой загрузчик модов; подготовка также зависит от совместимой Java, операционной системы, модов и доступности файлов выбранной версии. Проверка метаданных и команды запуска для 925 записей на Windows x64 не является проверкой запуска и игры во всех этих версиях.

Открой **Сборки**. Нажатие на название выбирает сборку для игры. Чтобы изменить её содержимое, нажми кнопку **Настройки** с шестерёнкой в той же строке. В открывшейся сборке выбери **Моды**, **Шейдеры**, **Ресурс-паки** или **Миры и копии**. Вкладка **Ошибки сборки** хранит до 50 последних сбоев этой сборки. Раскрой причину, чтобы увидеть время, действие, сообщение и подсказку. В верхней панели кнопка **Папка сборки** открывает её каталог. Запуск игры находится на главной, а общий ник редактируется в профиле.

Нажми звёздочку слева от **Настройки**, чтобы добавить сборку в избранное или убрать её. У избранной сборки звёздочка залита, а сама сборка находится в начале списка. Переключатель **Избранное** над списком оставляет только отмеченные сборки; поиск продолжает действовать. Отметки сохраняются после перезапуска.

Рядом с установленными файлами отображаются иконки из JAR, ZIP или карточки проекта. Лаунчер сохраняет изображения на компьютере. Для дополнения без изображения используется значок его категории.

- **Скачать** открывает каталог модов, шейдеров или ресурс-паков для версии игры и загрузчика сборки. Отметь кнопкой «+» несколько проектов. При поиске и переходе между страницами выбор сохраняется. В поле **Источник** можно оставить общий поиск или выбрать **Авторы на GitHub**. В выпуске 2.5.0 проверены 32 файла из 10 авторских репозиториев. Чтобы указать конкретный выпуск, открой карточку проекта. Перейди к выбранным дополнениям, проверь зависимости и нажми **Установить выбранное**.
- **Добавить файл** открывает файл с компьютера. Если в JAR мода объявлены обязательные зависимости, действие **Подобрать зависимости** ищет совместимые выпуски.

**Фильтры каталога.** Открой **Фильтры** рядом с поиском. Можно включать и исключать категории, выбирать клиентскую или серверную сторону для модов, эффекты и нагрузку для шейдеров, особенности и разрешение для ресурс-паков. Также доступны открытая лицензия, поиск по зависимостям и дополнительные исключения. Нажми **Применить**. Сортировка рядом позволяет искать, например, самые скачиваемые или недавно обновлённые проекты. При смене страницы и возвращении из карточки твой выбор сохраняется.

Обязательные зависимости проверяются для всего выбранного набора, включая зависимости библиотек. Общая библиотека скачивается один раз. Перед добавлением файлов лаунчер сверяет контрольные суммы и требования внутри JAR. Если обязательную зависимость не удаётся подобрать или заявленные версии несовместимы, в окне установки появится причина. Необязательные дополнения перечисляются отдельно. Конфликты поведения без признаков в метаданных могут проявиться только в игре.

| Категория | Что добавить | Как включить в игре |
| --- | --- | --- |
| Моды | JAR для выбранного загрузчика и версии Minecraft | Запусти сборку с этим загрузчиком. Если Minecraft был открыт, перезапусти его. |
| Шейдеры | ZIP с папкой `shaders` | В сборке нужен совместимый мод для шейдеров, например Iris на Fabric. Выбери установленный шейдерпак в настройках графики Minecraft. |
| Ресурс-паки | ZIP с `pack.mcmeta` в корне | Открой **Настройки → Наборы ресурсов** в Minecraft и включи пакет. Ресурс-паки работают и на Vanilla. |

Переключатель отключает дополнение без удаления файла. Выдели несколько строк для группового включения, отключения или удаления. Нажми название, чтобы посмотреть зависимости. Удалению и изменению состава предшествует точка восстановления. Каждая сборка хранит собственные миры, моды, шейдеры, ресурс-паки и настройки. Для совместной игры сверьте версии игры, загрузчика и модов, которые требуются сервером и клиентами. Шейдеры и ресурс-паки могут различаться.

### Удаление и восстановление сборки

Открой **Сборки**, нажми **Удалить** в строке нужной сборки. Действие выполняется сразу, без окна подтверждения. Её миры, моды, шейдеры, ресурс-паки и настройки переместятся вместе в `%LOCALAPPDATA%\BlockHarbor\deleted-instances`. Удаление активной сборки переключит лаунчер на одну из оставшихся. Последнюю сборку тоже можно удалить.

Чтобы вернуть сборку, раскрой **Удалённые сборки** и нажми **Восстановить**. Эта возможность сохраняется после перезапуска. Для освобождения места в этом же списке выбери **Удалить с диска**. Лаунчер сразу сотрёт папку выбранной удалённой сборки вместе с мирами и дополнениями.

## Производительность

В **Настройки → Память Minecraft** пустое поле включает автоматический подбор памяти по объёму физической и доступной ОЗУ. Выбранный лимит находится между 1 и 6 ГиБ. Чтобы задать собственный лимит, введи количество МБ и сохрани настройки. После обновления ранее введённое число продолжает действовать. Для автоматического режима очисти поле и сохрани.

Ранее применённые к сборкам параметры графики и памяти сохраняются после обновления. В версии 2.3 отдельная кнопка профилей производительности убрана из панели сборки. Совместимые моды оптимизации можно искать в каталоге дополнений через **Сборки → Настройки → Моды → Скачать**.

Лаунчер получает состояние сборок без открытия SQLite для каждого JAR. Для скрытого окна интервал проверки задач увеличен до минуты. Возвращение окна после закрытия Minecraft отслеживает процесс игры.

## Как играть с друзьями через Steam

Steam-соединение доступно только для сочетаний Minecraft и загрузчика, для которых в лаунчере есть совместимый комплект e4steam и Public Servers. При отсутствии такого комплекта можно продолжить обычную игру без Steam; одиночные миры и стандартное подключение к серверам Minecraft используют возможности самой выбранной версии.

На обоих компьютерах должен быть запущен настольный Steam. Войдите каждый в свой аккаунт, добавьтесь в друзья и выберите в BlockHarbor одну и ту же версию Minecraft, загрузчика и игровых модов. Для Steam-соединения VPN, публичный IP и настройка портов не требуются. [Steam для Windows](https://store.steampowered.com/about/)

В **Друзья** есть кнопка **Открыть Steam**, сведения о совместимости выбранной сборки и инструкция для хозяина и гостя. После входа в Steam выберите одну и ту же сборку в BlockHarbor и нажмите **Играть** на главной. Поддерживаемую Vanilla-сборку можно перевести на Fabric кнопкой **Включить Steam в этой сборке**. Это сохраняет версию игры и каталог миров. Для первой подготовки сетевых компонентов требуется интернет.

В **Друзья → Проверить подключение** показаны установленные сетевые компоненты, версия загрузчика, код набора модов и сведения из последнего журнала Minecraft. Сравните код и версии с хозяином мира. При отключённом открытии мира или неверном Steam App ID доступно исправление настроек с резервной копией. Недостающие компоненты можно подготовить здесь же.

Кнопка **Открыть Steam** запускает установленный клиент. Если клиент отсутствует, открывается официальная страница установки. Каждый участник входит в собственный аккаунт Steam.

Загрузки компонентов учитывают доступный системный HTTP(S)-прокси и повторяют временные сетевые ошибки. VPN может продолжать работать во время игры, если пропускает игровой трафик Steam. При блокировке транспорта Steam или UDP нужно разрешить этот трафик в настройках VPN или воспользоваться его раздельным туннелированием. Сам лаунчер не может изменить ограничения VPN-сервера. Результат реального соединения виден в журнале сборки и проверке во вкладке **Друзья**.

### Закрытый мир для компании

1. Хозяин открывает одиночный мир и выбирает **Esc → Открыть для сети**. В настройках доступа выбирает **Для друзей Steam** или **Только по приглашению**, затем открывает мир.
2. В чате Minecraft появится кнопка **Пригласить друзей**. Хозяин нажимает её и отправляет приглашение другу через Steam.
3. Друг запускает совместимую сборку, принимает приглашение Steam и подтверждает вход в Minecraft. Хозяин остаётся в мире до конца игры. Оверлей Steam обычно открывается сочетанием **Shift + Tab**.
4. Если приглашение не появилось, проверьте режим доступа и онлайн-статус в Steam. Хозяин также может передать другу зелёный адрес вида `s-<id>-<код>.steam` из чата. Скопируй его целиком вместе с окончанием `.steam`. Его можно вставить в **Сетевая игра → Прямое подключение**. Адрес действует для текущего сеанса. [Инструкция e4steam](https://github.com/Kamilhik/e4steam/blob/v0.3.6/docs/GETTING_STARTED.md)

### Общий каталог миров

Чтобы опубликовать мир для других игроков, хозяин выбирает **Открыть для сети → Общий сервер**, подтверждает публикацию, указывает название и открывает мир. Гость открывает **Сетевая игра → Публичные серверы**, находит название и нажимает **Подключиться**. Для приватной игры используйте приглашение по инструкции выше. [Релиз Public Servers 0.1.0](https://github.com/K2-Studio-Development/e4steam-Public-Servers/releases/tag/v0.1.0)

## Данные и сборка из исходников

Данные сохраняются в `%LOCALAPPDATA%\BlockHarbor`. Кнопка **Папка сборки** открывает каталог конкретного экземпляра, включая `saves` с мирами. Если Minecraft завершится с ошибкой при прямом запуске, BlockHarbor покажет сообщение. Игровой журнал находится в `logs\latest.log` внутри папки сборки. Повторный запуск BlockHarbor открывает отдельное окно с собственным выбором сборки.

Режим **Свой Microsoft Client ID** нужен пользователям с собственным приложением, одобренным для Minecraft Services. Укажи Microsoft redirect URI `http://localhost:43821/callback`. Вход использует OAuth с PKCE. Обычный локальный запуск и Microsoft через Prism не требуют регистрации приложения.

Приложение слушает только случайный порт на `127.0.0.1`. Окну передаётся временный ключ сессии. Интернет используется при запросе каталога/файлов игры, установке выбранных компонентов, входе и сетевой игре. Добавляемые вручную моды выполняются внутри Minecraft. Лаунчер проверяет структуру импортируемого файла и соответствие категории.

В `tools/windows-lock.json` приведены поставщики, версии и контрольные суммы компонентов. Условия распространения включённых компонентов находятся в [THIRD_PARTY.md](THIRD_PARTY.md).

### Запуск исходников

Для исходного проекта нужен Python 3.11 или новее. Выполни команды в корне репозитория. После первого запуска готового EXE исходники также доступны внутри текущего каталога `files-…` в `%LOCALAPPDATA%\BlockHarbor\app`.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m unittest discover -s tests
.\.venv\Scripts\python main.py
```

### Сборка приложения и установщика

Для создания Windows x64 EXE и установщика нужны Python 3.10 или новее и Go 1.25 или новее. Для установщика дополнительно нужен NSIS 3.13 или новее. Go используется также для отдельного компонента безопасного удаления данных. Команда сборки приложения получает закреплённый CPython и зависимости по HTTPS, сверяет SHA-256 и сохраняет архивы в кэш сборщика. Каталог назначения приложения должен быть новым или пустым.

```powershell
py -3.13 tools/build_windows.py --output ..\BlockHarbor-Windows-x64
py -3.13 tools/build_installer.py --launcher ..\BlockHarbor-Windows-x64\BlockHarbor.exe --output ..\BlockHarbor-Setup-2.6.0.exe --version 2.6.0 --project-url https://github.com/dedt1mon/BlockHarbor
```

Для релиза также создай манифест совместимости: `py -3.13 tools/release_update_manifest.py --version 2.6.0 --installer ..\BlockHarbor-Setup-2.6.0.exe --output ..\BlockHarbor-update.json`. Опубликуй его вместе с установщиком и `SHA256SUMS.txt`.

Если NSIS отсутствует в `PATH`, укажи компилятор явно через `--makensis "C:\Program Files (x86)\NSIS\makensis.exe"`. Для переносимого компилятора можно передать каталог данных NSIS через `--nsisdir`. Обе команды сборки принимают `--go` с путём к компилятору Go. Самостоятельный `BlockHarbor.exe` также запускается двойным щелчком и содержит тот же пакет приложения.

Поведение ярлыков и сценарии ручной проверки установщика описаны в [инструкции для Windows](docs/windows-installer.md).

Иконка хранится в `ui/icon.ico`, её исходная геометрия находится в `ui/icon.svg`. После изменения SVG выполни `python tools/render_windows_icon.py` в окружении с Pillow и пересобери приложение. Генератор Windows-ресурсов помещает иконку и сведения о версии в EXE при обычной сборке.

Для проверки извлечённого пакета готовой сборки можно вызвать `.\runtime\python.exe -m unittest discover -s tests`. Проверка распаковщика выполняется командой `go test tools/bootstrap_payload.go tools/bootstrap_payload_test.go`. Переносимая логика удаления проверяется командой `go -C tools/data_cleanup test .`; она не заменяет проверку деинсталлятора на Windows. Лог запуска оболочки лежит в `%LOCALAPPDATA%\BlockHarbor\logs\startup.log`.
