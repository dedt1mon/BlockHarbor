## BlockHarbor 2.6.3 — публикации и диагностика

- **Сборки → Настройки → Ошибки сборки:** кнопка «Проверить сборку» перенесена из списка ошибок в верхнюю панель, справа от «Папка сборки». Пустое состояние «Пока нет записанных ошибок» занимает всю доступную ширину.
- **Проверить сборку → Посмотреть отчёт:** кнопки переставлены местами: слева «Вернуться обратно», справа **«Сохранить отчёт»**. Обе занимают одинаковую ширину. Возврат сохраняет уже введённые правки отчёта и не запускает диагностику заново.
- **Сборки → Поделиться:** кнопки «Закрыть» и «Опубликовать» равномерно заполняют ширину окна.
- **Опубликованная сборка:** больше нет раскрывающегося списка «Опубликованные сборки». Код сборки и «Скопировать ID» показываются сразу; ниже — две равные кнопки «Удалить публикацию» и «Закрыть».
- Удаление публикации по-прежнему требует явного подтверждения. При наличии нескольких публикаций каждый код отображается отдельно; можно снять именно нужную публикацию.
- Пока состояние публикации проверяется, повторная отправка заблокирована; при ошибке проверки доступна кнопка повторной попытки.

**Для Windows x64:** установщик `BlockHarbor-Setup-2.6.3.exe`. После публикации релиза обновление также доступно через стандартный механизм проверки новых версий лаунчера.
