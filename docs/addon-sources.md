# Источники дополнений

Встроенный каталог модов, шейдеров и ресурс-паков объединяет Modrinth с проверенными выпусками авторов на GitHub. Один проект не дублируется, у карточки указано происхождение. Объединение выполняется по подтверждённому идентификатору проекта: разные проекты с одинаковым названием остаются отдельными карточками. Перед показом проверяется выпуск для точной версии Minecraft и загрузчика, наличие допустимого файла, его размер и SHA-512. Уже установленные файлы определяются по содержимому, включая переименованные и отключённые дополнения.

Поиск повторно использует сведения о проекте из ответа Modrinth: на обычной странице из 12 проектов требуется 13 запросов вместо 25 — поиск и список выпусков каждого проекта. Проверки выпусков идут параллельно в ограниченном пуле. Общий срок поиска ограничен 20 секундами, подключение для метаданных — 8 секундами. Ответы кэшируются на пять минут, изменение запроса отменяет предыдущую работу. Если Modrinth недоступен, доступные проверенные выпуски GitHub показываются с явным сообщением о неполной выдаче.

## CurseForge и Planet Minecraft

Внешние ссылки «Поиск на сайтах» удалены. CurseForge и Planet Minecraft пока не подключены к встроенному каталогу; ответ API помечает их как `disabled` с конкретной причиной. Они не добавляют карточки, не увеличивают счётчик результатов и не создают сетевых ожиданий.

Для встроенного API CurseForge нужен одобренный ключ разработчика. Он не предоставлен и не зашит в лаунчер. CurseForge также требует ключ для прямых загрузок с CDN. Интеграция должна учитывать разрешение автора на стороннее распространение; обходные прокси или чужие ключи не используются.

Planet Minecraft требует отдельное письменное разрешение на импорт данных сайта в приложения. В проект не предоставлены ни такое разрешение, ни согласованный интерфейс получения каталога.

### Что нужно для подключения

1. Получить одобренный ключ CurseForge для BlockHarbor и согласовать его использование для поиска и скачивания. Ключ не следует передавать в чате или включать в публичный репозиторий. Для производственной конфигурации требуется защищённое хранение, а запросы API и CDN должны передавать ключ в заголовке `x-api-key`.
2. Получить письменное разрешение Planet Minecraft и описание разрешённого способа получения метаданных и файлов.
3. После предоставления доступа реализовать и проверить полный путь каждого источника: поиск, точную версию Minecraft и загрузчика, разрешение автора на распространение, получение файла, контроль целостности, зависимости и определение уже установленного дополнения. Сопоставлять проекты разных площадок можно по подтверждённым связям или одинаковому содержимому файла; совпадения названий недостаточно.

Настройки ключа в текущем выпуске нет: один ключ без реализации и проверки полного пути ещё не включает источник. До получения доступа рабочими встроенными источниками остаются Modrinth и проверенные выпуски авторов на GitHub.
