# Источники дополнений

Встроенный каталог модов, шейдеров и ресурс-паков объединяет Modrinth с проверенными выпусками авторов на GitHub. Один проект не дублируется, у карточки указано происхождение. Перед показом проверяется выпуск для точной версии Minecraft и загрузчика, наличие допустимого файла, его размер и SHA-512. Уже установленные файлы определяются по содержимому, включая переименованные и отключённые дополнения.

Поиск повторно использует сведения о проекте из ответа Modrinth: на обычной странице из 12 проектов требуется 13 запросов вместо 25 — поиск и список выпусков каждого проекта. Проверки выпусков идут параллельно в ограниченном пуле. Общий срок поиска ограничен 20 секундами, подключение для метаданных — 8 секундами. Ответы кэшируются на пять минут, изменение запроса отменяет предыдущую работу. Если Modrinth недоступен, доступные проверенные выпуски GitHub показываются с явным сообщением о неполной выдаче.

## CurseForge и Planet Minecraft

В разделе «Поиск на сайтах» открывается официальный сайт с текущим запросом и выбранным типом дополнения. CurseForge также получает версию Minecraft. Ссылки создаются без сетевого ожидания; они доступны при недоступности встроенного каталога. Эти сайты не добавляют непроверенные карточки в результаты и не увеличивают счётчик встроенного каталога. Скачанный вручную файл можно добавить штатной кнопкой добавления дополнения.

Для встроенного API CurseForge нужен одобренный ключ разработчика. Он не предоставлен и не зашит в лаунчер. CurseForge также требует ключ для прямых загрузок с CDN. Интеграция должна учитывать разрешение автора на стороннее распространение; обходные прокси или чужие ключи не используются.

Planet Minecraft требует отдельное разрешение на импорт данных сайта в приложения. Текущая интеграция открывает обычную страницу поиска. Она не извлекает HTML-каталог или ссылки скачивания автоматически.
