# BlockHarbor 2.6.8 — надёжная загрузка NeoForge

- При обрыве соединения с Maven NeoForge лаунчер повторяет запрос через независимый HTTPS-транспорт; увеличен тайм-аут чтения для этого источника, без отключения проверки сертификатов.
- Исправляется форма старых адресов NeoForge Maven без `/releases/`. Для файлов с контрольной суммой из исходного источника предусмотрены резервные Maven-репозитории; несовпадающие файлы отклоняются. Для установщика при отсутствии переданного SHA-1 запрашивается официальная контрольная сумма. Неподтверждённые зеркала не используются без исходного хеша.
- Сохранены атомарная запись, повторное использование проверенных файлов и отмена операций при закрытии лаунчера. Сообщение об ошибке сетевой загрузки NeoForge уточняет имя файла и характер сбоя.
- Добавлены регрессионные тесты альтернативного транспорта, зеркал, проверки хешей и отказа без доверенной контрольной суммы. Версия Minecraft, NeoForge и модов не изменяется автоматически.

Резервные источники не гарантируют доступность каждой версии. Если ни один доступный источник не предоставит проверяемый файл, установка остановится безопасно. Существующие миры и сборки не удаляются.
