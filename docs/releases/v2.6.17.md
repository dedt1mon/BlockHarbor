# BlockHarbor 2.6.17

## Подготовка NeoForge после переноса сборки

Исправлен путь, на котором импортированная ZIP-сборка могла останавливаться с сообщением `Не удалось скачать neoforge-21.1.267-installer.jar с maven.neoforged.net: истекло время ожидания ответа` и требовать повторного нажатия **Играть**.

ZIP сохраняет выбранные Minecraft, загрузчик, моды и настройки. Java, файлы игры и установщик загрузчика подготавливаются на компьютере получателя. Версия NeoForge из архива остаётся закреплённой: лаунчер не заменяет её произвольным новым выпуском.

### Что исправлено

- Получение контрольной суммы установщика с основного сервера NeoForge больше не использует одно короткое обращение фонового каталога. При временном сбое предусмотрены ограниченные повторы через два HTTPS-транспорта.
- Если основной сервер не отдаёт установщик, доступен резервный путь. Полученный файл принимается только при совпадении с контрольной суммой из доверенного источника. Проверка сертификатов остаётся включённой.
- Для указанной в ошибке версии `21.1.267` в выпуск включена заранее проверенная официальная контрольная сумма. Поэтому на чистом компьютере резервная загрузка возможна и тогда, когда основной сервер не отдаёт даже файл checksum.
- Успешно проверенный установщик сохраняется в общем кеше лаунчера. Если Java или следующая стадия установки завершается ошибкой, новый запуск использует этот JAR после повторной проверки, даже когда временная папка предыдущей попытки уже удалена.
- Для другой импортированной сборки с теми же Minecraft и NeoForge можно использовать завершённую общую установку. Лаунчер проверяет её подтверждение и реальные файлы; одного существования JSON-профиля после неудачной установки недостаточно.
- Повторы загрузки установщика имеют общий бюджет времени. Проверка кеша, повтор и резервная загрузка отображаются справа внизу; результат операции сохраняется в истории уведомлений.

### Проверка выпуска

Регрессионные проверки воспроизводят сбой получения checksum, повтор после удаления временной папки установщика, повреждённый кеш, разделение версий и незавершённую установку. В проверку настоящего Windows EXE включены скачивание точного NeoForge `21.1.267`, сверка файла, принудительный отказ основного пути с реальной резервной загрузкой и повторное использование кеша при запрещённой сети.

Эти проверки относятся к подготовке загрузчика. Они не подменяют проверку конкретного набора модов в работающем Minecraft и совместной игры на компьютерах пользователей.

## Как обновиться

1. Заверши игру и закрой окна BlockHarbor.
2. Установи `BlockHarbor-Setup-2.6.17.exe` в прежнюю папку приложения или воспользуйся обновлением лаунчера.
3. Открой уже импортированную сборку и нажми **Играть**. Удалять её, миры или заново передавать ZIP для этого исправления не требуется.

Исправление должно быть установлено у получателя сборки — именно его лаунчер скачивает NeoForge. Первая подготовка на чистом компьютере требует доступа к серверам файлов. Если все доступные пути недоступны, лаунчер завершает операцию с ошибкой, сохраняя ранее проверенные файлы.

Функция **Поделиться** остаётся временно отключённой. Отдельные **Выгрузить** и **Загрузить сборку**, каталог модпаков и гардероб работают как прежде.
