# Изменения BlockHarbor

## 2.5.0 — 20 ноября 2026

- Список загрузчиков открывается из локального каталога. Для Forge сохранены полные имена опубликованных установщиков, в том числе суффикс сборки 1.7.10 и обозначение 1.7.10-pre4. Для Forge 1.5.2 основная библиотека извлекается из установщика.
- В каталоге дополнений можно отметить несколько проектов, продолжить поиск и установить весь выбор вместе. По кнопке «Скачать» доступны также проверенные выпуски из официальных репозиториев авторов на GitHub.
- Перед установкой проверяются общие и вложенные обязательные зависимости, в том числе указанные в файле мода. Если библиотеку не удаётся подобрать, лаунчер показывает причину до изменения сборки.
- В настройках каждой сборки появился раздел «Ошибки сборки» с группировкой по причине, подсказками и выдержками из журнала. После аварийного выхода из игры туда можно перейти из уведомления.

## 2.4.11 — 19 ноября 2026

- Полоса прокрутки списка версий Minecraft в форме новой сборки помещена внутрь рамки со скруглёнными краями.
- В настройках загрузок по умолчанию показываются четыре последние задачи. Более ранние записи раскрываются по желанию пользователя; список можно снова свернуть, не удаляя историю. Раскрытие сохраняется при обновлении состояния, а отмена, повтор и очистка истории продолжают работать.

## 2.4.10 — 19 ноября 2026

- Добавлена проверка совместимости Minecraft и загрузчика до создания сборки и новой установки. Неподдерживаемый Fabric/Quilt отклоняется до запроса профиля; ответы HTTP 400/404 дают понятное объяснение выбранной пары или закреплённой версии загрузчика. Временные сетевые ошибки сохраняют повторные попытки.
- В форме новой сборки недоступные загрузчики помечены, а кнопка «Выбрать Vanilla» требует явного перехода на игру без модов. Полный снимок официального каталога содержит 925 записей, включая 103 релиза; снапшоты, бета-версии и ранние выпуски открываются переключателем «Показывать снапшоты и старые версии». Обновление списков доступно из формы, сохранённые каталоги используются при сетевом сбое.
- Исторические идентификаторы Minecraft с пробелами обрабатываются без переименования; пути и запрещённые имена Windows отклоняются. Подбор NeoForge понимает календарные версии Minecraft 26.x, а каталог Forge сохраняет такие версии после обновления.
- Существующие сборки сохраняют закреплённые загрузчики и локальные файлы. Проверка поддержки не требует сети для повторного запуска уже установленной сборки и не подменяет проверку совместимости Steam.
- Из поля названия новой сборки убрана зелёная подсветка фокуса. Метаданные и формирование команды проверены для всех 925 записей на Windows x64; это не означает проверку игрового запуска каждой версии.

## 2.4.9 — 19 ноября 2026

- Исправлено определение библиотек по явным `artifact.path`, платформенным `classifiers`, правилам ОС и наследованию версии. Записи только с `classifiers` больше не создают ложное требование обычных `lwjgl-platform-2.9.1.jar` и `jinput-platform-2.0.5.jar`; для прежних метаданных без `downloads` сохранён Maven-путь.
- Исправлен фактический список библиотек команды запуска, включая `-DlegacyClassPath` старых загрузчиков. Аргументы модульной системы сохраняются, глобальная подмена библиотеки запуска не применяется.
- Проверка полноты и восстановление файлов используют те же объявления и размеры, включая обязательные платформенные файлы. Проверки контрольных сумм, атомарные загрузки, повторы и отмена сохраняются.
- Существующую сборку можно повторно запустить кнопкой «Играть» после обновления: лаунчер перепроверит необходимые компоненты. Исправление не заявляет проверку игрового запуска всех версий Minecraft и загрузчиков.

## 2.4.8 — 19 ноября 2026

- Звёздочка избранного перенесена влево от кнопки «Настройки» сборки.
- Добавлены короткие CSS-переходы при взаимодействии с интерфейсом с учётом настройки уменьшения анимации и системного `prefers-reduced-motion`.
- Зелёная подсветка фокуса в поисковых полях заменена нейтральным выделением.
- Из каталога сборок убрана кнопка «Импорт .mrpack», а высота кнопки «Найти» согласована с полем поиска.

## 2.4.7 — 19 ноября 2026

- Отсутствие совместимого комплекта e4steam для выбранной версии Minecraft и загрузчика больше не блокирует создание сборки, подготовку файлов и запуск игры без Steam.
- Перед загрузкой появляется окно «Игра без подключения через Steam» с кнопками «Отмена» и «Продолжить без Steam». Подтверждение запоминается для сборки и не повторяется при каждом запуске.
- Закреплённые версии и файлы сетевых компонентов сохранены. Доступность самой игры, загрузчика и подходящей Java проверяется отдельно от поддержки Steam.

## 2.4.6 — 19 ноября 2026

- Рядом с кнопкой «Настройки» каждой сборки добавлена звёздочка для добавления в избранное и снятия отметки.
- Контурная и залитая звезда отражают текущее состояние. Отметки сохраняются после перезапуска, учитываются сортировкой и фильтром «Избранное».

## 2.4.5 — 19 ноября 2026

- Поменяны местами иконки загрузки и выгрузки сборок: у «Загрузить сборку» стрелка вниз, у «Выгрузить» стрелка вверх.
- Значок загрузки приведён к одному виду на главной, в списке сборок и на экране без выбранной сборки.

## 2.4.4 — 19 ноября 2026

- Из настроек сборки убраны кнопки «Выгрузить .mrpack», «Оформление» и «Играть», поле «Ник в игре» и кнопка «Сохранить ник». В верхней панели остаётся «Папка сборки».
- Редактирование общего ника находится только в разделе «Профиль». На главной остаётся запуск игры с уже сохранённым ником.
- Из профиля удалена кнопка «Сохранить только для Java-профиля». Ник, модель и скин сохраняются общей кнопкой «Сохранить все параметры»; установка скина в официальный Java-профиль сохранена.
- Из списка сборок удалён выпадающий список «Все группы». Поиск и фильтр сохранённого избранного доступны, существующие метаданные сборок сохраняются.
- Удалены доказанно неиспользуемые клиентские обработчики и стили старых элементов интерфейса. Серверные механизмы, данные и сохранённые настройки сохранены для совместимости.
- Импорт `.mrpack` и каталог Modrinth, выгрузка и загрузка ZIP, миры и резервные копии продолжают работать через прежние доступные действия.

## 2.4.3 — 18 ноября 2026

- Исправлен ввод ника на новой установке: поле и сохранение доступны без сборки. На главной добавлена кнопка «Сохранить ник».
- Параметры персонажа сохраняются в общем профиле лаунчера. Сохранение ника, модели и PNG не требует выбранной сборки или установки модов; совместимые сборки получают скин при следующем запуске.
- Создание, выбор и импорт сборок не сбрасывают ник. Общий черновик Главной и Профиля сохраняется при навигации и выборе скина из гардероба; завершение раннего запроса не перезаписывает более поздний ввод.
- Пустой или неверный ник отклоняется вместо незаметной подмены прежним именем. При запуске ник сохраняется до подготовки файлов, даже если последующая загрузка завершается ошибкой.
- Сохранены независимые профили уже открытых окон, официальное имя Microsoft-аккаунта и явное подтверждение перехода на Fabric для скина.

## 2.4.2 — 18 ноября 2026

- Разрешено штатное разворачивание окна лаунчера и изменение его размера без ограничения 1360×840. Этот размер теперь используется только при обычном открытии с учётом DPI и рабочей области монитора.
- Обработчик регистрации больше не восстанавливает развёрнутое окно и не меняет выбранный пользователем размер после открытия.
- Интерфейс занимает всю доступную ширину и высоту окна. Уведомления привязаны к правому нижнему углу окна.
- Убраны повторные запросы подгонки окна при изменении его размеров; регистрация и завершение сеанса продолжают работать при загрузке и закрытии страницы.

## 2.4.1 — 18 ноября 2026

- Из раздела «Друзья» убран блок «Одинаковая сборка для друзей», включая вариант «Сборка друга» при пустом списке сборок и ручной обмен описанием `.bhshare`.

## 2.4.0 — 18 ноября 2026

- Убрано создание служебной консоли при распаковке приложения и подготовке Java, Minecraft и загрузчиков. Служебные процессы Windows запускаются без отдельного консольного окна; их вывод остаётся доступен обработчику операции и журналам.
- Прогресс подготовки и обновления отображается в уведомлении справа снизу. После первой распаковки уведомление появляется при открытии интерфейса.
- При ограничении GitHub API (403/429) сведения об обновлении получаются через публичные файлы релиза. Сохраняются ограничения HTTPS/репозитория, проверка размера, SHA-256 и схемы данных.
- Добавлены общий для окон кэш проверок и ожидание до разрешённого времени следующего API-запроса. Повторные нажатия не расходуют лимит одинаковыми запросами.
- Манифест выпуска дополнен именем, размером и SHA-256 установщика. Старые клиенты продолжают читать прежние поля совместимости.
- Для 2.3 с уже исчерпанным лимитом предусмотрен обычный переход новым установщиком; игровые данные не меняются.

## 2.3.0 — 18 ноября 2026

- Канал обновлений использует оформление полей Профиля: фон, рамка, стрелка, список и фокус. Сохранение канала устойчиво к запоздавшим ответам обновления состояния; ошибка возвращает прежний канал.
- Деинсталлятор предлагает удалить только приложение или приложение вместе с локальными данными. Безопасный вариант с сохранением сборок и миров выбран по умолчанию; тихое удаление также сохраняет данные.
- Полная очистка ограничена стандартной папкой BlockHarbor и проверяет активные сеансы. Ссылки и junction удаляются как ссылки, их внешние цели не обходятся.
- Действия в настройках сборки собраны справа, сведения о версии и загрузчике остаются слева. Группа переносится при недостаточной ширине.
- Убраны кнопки «Восстановление», «Сделать копию», «Производительность», «Диагностика» и «Ярлык» из верхней панели. Вкладка «Миры и копии», сохранённые точки, автоматические копии и диагностика после сбоя сохранены.
- Выпуск устанавливается механизмом автоматического обновления 2.2; схема данных остаётся прежней.

## 2.2.0 — 18 ноября 2026

- Исправлен ложный отказ запуска из-за завершающей работу старой версии. Новая версия ожидает освобождения реальной блокировки; окно ожидания в Windows показывает причину и позволяет отменить запуск.
- Ошибки доступа Windows отделены от занятой блокировки, исправлено освобождение Win32 handles. Старый файл блокировки без владельца не блокирует приложение.
- Автоматическое обновление из GitHub с переключателем в **Настройки → Загрузки и обновления**: проверка при открытии и каждые 10 минут активного сеанса, проверка размера, SHA-256 и схемы данных.
- Тихая установка проверенного выпуска после завершения игр, загрузок, операций и закрытия других окон. Сохраняются папка приложения и ярлыки; после успеха открывается одно окно. Неудачная автоустановка того же выпуска не образует цикл перезапусков.
- Ручное закрытие отменяет операции, ожидание обновления и принадлежащие окну служебные процессы. Проверка обновлений не остаётся работать после закрытия. Нет автозапуска, фоновой службы или заданий планировщика.
- Разделены ручное закрытие, обновление страницы и автоматическое скрытие во время игры. Запущенные Minecraft и другие окна не закрываются принудительно.
- Отменяемые сетевые чтения, ожидания межпроцессных блокировок и подготовка Java; отмена импорта/резервного копирования сохраняет существующие сборки и миры.

Первый переход со старой версии выполняется новым установщиком или прежней кнопкой обновления. Автоматический механизм действует начиная с 2.2. При оставшейся версии 2.0 новая копия может ждать до трёх минут, пока старый процесс закончит свою прежнюю задержку закрытия. Реальная занятость файлов не обходится.

## 2.1.0 — 18 ноября 2026

- Каждый запуск приложения открывает отдельное окно. Можно одновременно играть из разных сборок; активная сборка и локальный ник независимы в каждом окне.
- Согласование файловых операций между окнами, защита занятой сборки и ожидание завершения сеансов перед обновлением приложения.
- Каталог сборок перенесён из левой панели в модальное окно **Сборки → Каталог сборок**. Поиск, категории, версия, загрузчик, сортировка, страница и выбранный выпуск сохраняются при переходах.
- **Миры и копии** находятся внутри настроек сборки, справа от вкладки **Ресурс-паки**.
- В галерее можно удалять отдельные скриншоты и выбранную группу. Удалённые снимки доступны для восстановления; изменившийся файл и совпадающее имя при восстановлении не перезаписываются.
- Загрузки и обновления перенесены в отдельную вкладку общих настроек. Индикатор нового выпуска отображается рядом с настройками.
- Из списка дополнений убраны кнопки **Закрепить**, **Открепить**, **Проверить обновления** и ручного обновления списка.
- Иконка истории уведомлений заменена на колокольчик.
- Диагностика после вылета открывает отчёт соответствующей сборки, даже если выбрана или продолжает работать другая.

Для второго экземпляра того же набора модов используется отдельная копия сборки. Несколько игр не записывают настройки и миры в один каталог.

## 2.0.0 — 18 ноября 2026

### Сборки, моды и миры

- Точки восстановления перед изменениями, отдельные копии миров, история и клонирование сборок.
- Журнал замены файлов и восстановление после прерванной операции; проверка хешей архивов.
- Лимиты числа копий и занятого места, автоматические копии изменённых миров после выхода (включаются для каждой сборки).
- Названия, версии, описания и изображения установленных дополнений; поиск, групповые действия, включение без удаления и закрепление версий.
- Проверка доступных обновлений с точным планом, обязательными зависимостями и проверкой состава перед применением.
- Каталог готовых проектов Modrinth, импорт/экспорт `.mrpack` и поддержка прежнего ZIP.

### Совместная игра

- Описание сборки `.bhshare`/код: совпадения, недостающие и отличающиеся файлы, клиентские дополнения, точные проверенные загрузки.
- Подготовка отдельной общей сборки или проверенное изменение текущей с точкой восстановления.
- Приглашение с адресом текущего e4steam-сеанса и добавление в список серверов Minecraft без потери прежних записей.
- Собственный небольшой компонент статуса для поддерживаемых Fabric/Quilt: данные текущего сеанса и подтверждённые имена участников из Addon API e4steam. Для остальных загрузчиков источник журнала обозначен явно.

### Приложение и удобство

- Центр загрузок: байты, скорость, этапы, отмена, повтор и продолжение при поддержке HTTP Range.
- Встроенная проверка версий BlockHarbor, стабильный/тестовый канал, описание релиза, установка после выхода из игры, сохранение совместимой предыдущей версии.
- Обложки, описания, группы, избранное, фильтрация сборок, перетаскивание файлов и отдельные ярлыки.
- Гардероб скинов, галерея снимков, масштаб текста, уменьшение анимации и история уведомлений.
- Стабильная Windows AppUserModelID для принадлежащего лаунчеру окна и его ярлыков.

### Диагностика и производительность

- Четыре профиля настроек с предварительным просмотром и восстановлением предыдущих параметров.
- Добровольная установка совместимых модов оптимизации.
- Измерения времени подготовки, сеансов и расхода памяти процесса Java.
- Анализ распространённых ошибок запуска и зависимостей со строками журнала; ограниченное сохранение stderr Java.
- Предварительный просмотр и редактирование диагностического отчёта; типичные токены, адреса и личные пути скрываются перед экспортом. Отчёты никуда автоматически не отправляются.

Открытие мира и приглашение через Steam остаются в Minecraft. Компонент статуса не управляет миром. FPS не измеряется, полное отсутствие фризов не обещается. Проверки Windows-установщика и живой игры двух аккаунтов требуют запуска на Windows; автоматические проверки описаны в документации.
